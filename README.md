# 深路（ふかじ） / FUKAJI

自分自身の対局・研究から学び、棋力を高め続ける独立将棋AI。コード正本はこのリポジトリ。雲路は参照・比較対象。

## 正式USIエンジン（2026-10-31）

**FUKAJI v0.1.0**。オーナーの明示的な採用判断により、高速合法手生成を正式採用し、USIの `FastLegalGuard` 初期値を **true** に変更。以前の計算方法へ戻す必要がある場合は、USIの `setoption name FastLegalGuard value false` を指定できる。

採用根拠は、同一凍結G8モデルの独立240局で高速版100勝・従来版55勝・未決着85局。雲路との新200局では双方0勝で、まだ雲路への実力差が大きい。正式採用したのは**高速合法手生成のみ**であり、G8学習済みモデルの初期組込みやその他の研究設定の一括変更ではない。

[現行エンジン仕様・初期設定](docs/現行エンジン仕様.md)／[採用判断と理由](docs/decisions/2026-10-31_深路高速合法手正式採用.md)／[次の棋力向上方針](docs/ROADMAP.md)。

## 研究当時の現在地（2026-10-29、履歴）
- `fukaji/engine.py` はpython-shogiのルール処理と自作の反復深化・αβ探索を使う。`RelativeValue` の学習評価を読み込んで実際に対局できる。
- G8は手番相対2549特徴の線形評価。NNUEではない。研究比較は学習評価25%・高速相対評価と根元α境界再利用ON・200ms・深さ上限2。
- G8対G7の240局は88勝59敗・未決着93。優位の兆候はあるが、先後ペアを考慮した検定では確証に届かない。G8は研究候補で、正式採用はしていない。
- 小型NNUEの推論・差分更新・学習器、UCT、C++ルール処理は研究基盤。学習済みNNUEの実戦効果やUCTの棋力優位は未確認。
- 当時のUSI初期設定は研究比較と異なり、モデル未指定・SearchDepth=4だった。2026-10-31現在もG8モデルは明示ロードが必要。

## これからの研究：NNUEを主軸とする深路独自の路線

深路は**NNUEによる局面評価を中心に棋力を伸ばす**。雲路は別系統のAIで、探索効率や将棋ルールの一般的な技術を比較・独立検証することはあっても、雲路の手作業配点・戦略・研究手を深路の評価や教師に移植しない。

小型NNUEは学習器・差分累積器まで作成済みだが、現状ではG8線形評価より未知の自己対局400局での予測誤差が大きく、差分更新の負荷も高い。まず**学習収束・訓練分割・NNUE特徴表現・更新効率**の独立研究を行い、保持群予測と同じ200msの新局実戦でG8や正式版を超えられるか検証する。前のD15『玉周囲への手作業配点』は未実装のまま保留。[現行D16計画](docs/D16_NNUE_FIRST_ROADMAP_20261031.md) と [ROADMAP](docs/ROADMAP.md)を研究の入口とする。

作業開始は [AGENTS.md](AGENTS.md) → [開発ルーター](docs/00_開発ルーター.md)。実行入口は [Actions一覧](.github/workflows/README.md)。既存の時間保証・OSパイプ研究は記録を保全し、追加研究を保留する。

## 実行・データ
`python -m unittest discover -s tests -v` で既存の検査を実行する。依存は `requirements.txt` を用いる。研究対局は各workflowの固定モデルSHA・入力・明示requestを確認して起動する。

`selfplay.py` と `learning.py` のランダム対局・線形value-v0は初期基盤として残る。初期READMEの「モデル未接続」は現在のG8研究経路には当てはまらない。

外部AIの評価値・PV・推奨手は教師にしない。未決着を勝ちや引分の教師にしない。研究実装・学習実行・実戦検証・正式採用を別々に記録する。
