# 深路・独立C++ルール研究 第1段階（未採用）

**目的**：Python合法手生成の律速を減らす前に、独立C++の王手判定と局面反復計数が、現行の`python-shogi==1.1.1`と一致するか検査する。

- `rules_probe.cpp` はC++17標準ライブラリのみを使い、SFENを読み、先手・後手の王手判定と同一局面4回の検出を独立実装する。既存の雲路コード・外部AI探索・評価は移植しない。
- `tests/test_native_rules_probe.py` はGitHub Actionsの既存軽量CIでC++をビルドし、凍結した特殊局面とseed固定の到達可能局面について両側の王手判定を比較する。さらにPythonの疑似合法手を一手ずつ適用し、**C++の王手判定＋打ち歩詰めだけPython判定**で得られる合法手集合と、Pythonの正規合法手集合を比較する。打ち歩詰め禁止局面と4回反復も明示検査する。
- **未実装**：独立したC++合法手列挙、C++持駒・打ち歩詰め・連続王手千日手の完全規則、盤面push/pop、USI統合、探索接続。合法手の列挙と打ち歩詰めは引き続きPythonを利用するため、現時点では独立した高速ルールエンジンではない。
- **計測上の制約**：CIの王手等価性検査は正しさの検証のみ。Python↔C++の標準入出力往復やテスト全体の時間を200ms実戦速度と混同しない。既存FastLegalGuard・FastMoveListの既定OFFと正式雲路は変更しない。
- **次の段階**：独立C++盤面と合法手列挙・持駒・打ち歩詰め・連続王手千日手を段階的に実装。王手/ピン/成り/二歩/行き所のない駒を含む境界局面でPython正本との完全一致を検査した後、同一探索・同一モデルで速度を測定し、さらに独立先後交替の実戦で棋力を測る。未決着は勝利に含めない。

再現：`python -m pip install -r requirements.txt && python -m unittest tests.test_native_rules_probe -v`（g++必須）。
