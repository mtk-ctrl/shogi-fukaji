# 深路・独立C++ルール研究 第4段階・可逆着手状態（未採用）

**目的**：python-shogi 1.1.1 の疑似合法手生成・自玉王手除去・打ち歩詰め禁止を独立C++17で再現する。Engine未接続・研究用・既定OFF。

- `native/rules_probe.cpp` の `P <SFEN>` はC++独立の疑似合法手集合（盤上移動、成り、持駒打ち、二歩、行き所のない駒）。`H <SFEN>` はそれを独立王手判定と打ち歩詰め禁止で絞った**合法手集合**。いずれもソート済みUSIをカンマ区切りで1行出力。
- 既存 `C <b|w> <SFEN>` は指定側の王手、`R <SFEN>` は同一SFEN盤面・手番・持駒の4回反復、`Z` は履歴初期化。
- `tests/test_native_rules_probe.py` では固定の打ち歩詰め・非詰め特殊局面とseed固定の序盤・中盤到達局面について、Pythonの疑似合法手集合とC++ `P` の完全一致、C++ `H` の完全合法手集合の一致（Python補正なし）、王手・4回反復・異常入力を検査する。着手順は検証対象外。
- **新設**：`B <SFEN>`で局面を読み込み、`M <USI>`でC++の完全合法手検査後に着手・捕獲駒の持駒追加・成り・手番と手数を更新。`U`は直前の着手を取り消し、`S`は現在のSFEN、`F`は現在の局面の4回反復の有無を返す。`B/M/U/S`は正規化SFENを返す。`Z`は履歴と状態を初期化。研究専用の可逆局面で、通常Engineは使用しない。
- **検証**：捕獲・成り・持駒打ちの固定局面、seed固定6系列×最大70手で全手のSFENと逆順undoをpython-shogi 1.1.1に照合。4回反復とundoの履歴復元を確認。
- **未実装**：連続王手千日手の勝敗区別、Engine統合、実戦速度/棋力測定。`H` は独立した合法手列挙の研究プローブであり、対局履歴や時間管理を備えた完全エンジンではない。**実戦エンジンへは未接続**。
- 速度の根拠にはこの標準入出力プロトコルのテスト所要時間を使用しない。正しさの検査を通過した後、同じ探索条件で専用の速度測定を行う。雲路正式版は変更しない。

再現：`python -m pip install -r requirements.txt && python -m unittest tests.test_native_rules_probe -v`（g++必須）。
