## 正式採用の変更
`fukaji/engine.py`：正式USIの `FastLegalGuard` default をtrueへ変更（旧版false）、USI名をFUKAJI v0.1.0に更新。研究用 `select_move` Python APIの旧既定falseは固定比較の再現を維持。明示USI `setoption name FastLegalGuard value false` で過去版を選択可能。学習モデル・正式SearchDepth4・ほかのUSI既定値は不変。G8モデルの配布と自動初期ロードはまだ研究範囲外。

`tests/test_fast_legal_guard.py` にUSI既定true・明示true/falseの互換回帰を記録。現行仕様 `docs/現行エンジン仕様.md`、README・ROADMAPの状態を整合。バージョンはEngineの変更であるため0→0.1.0とした（研究モデル世代G8とは独立）。

## 次の研究（D14）
深路の対雲路200局全敗と過去20局の最後の受け5局は逃げ手あり・15局は手遅れという結果から、敵玉や自玉への王手・詰み脅威を評価の末端で扱う必要が高い。既存の全静止探索はD3のG8 200ms局面で4/5ほど深さ後退したため、そのまま復活させず、**王手中の末端だけ1手延長して受け全候補を調べる軽量な単一要因候補**を検討する。危険回避の正答だけでなく、実時間・深さ3完了率を比較し、深さの大幅退行なら採用しない。次に新seed40→240局で採否判断へ。
