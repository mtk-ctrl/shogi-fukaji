# 深路（FUKAJI）現行エンジン仕様

更新：2026-10-31。深路の正式USIエンジンは **FUKAJI v0.1.0**。正本は `fukaji/engine.py`。本書は `mtk-ctrl/shogi-fukaji` 固有であり、雲路の版番号とは別。

## 正式採用：高速合法手生成

2026-10-31の本人の明示指示「深路としては強くなってるよね。正式採用でしょ。」により、以前の研究候補 `FastLegalGuard` を正式USI既定 **ON** で採用した。

- `usi` で `id name FUKAJI v0.1.0` を名乗る。
- `option name FastLegalGuard type check default true`。必要な再現対照試験では `setoption name FastLegalGuard value false` でOFFにできる。
- 研究用Python関数 `select_move(...,fast_legal_guard=False)` 等の省略時既定は過去の研究比較を壊さないようOFFのまま。**正式既定**はUSIで指定がない場合のONであり、研究呼出しの省略時既定と区別する。
- 高速化は合法手の検査処理を保守的に省略するもの。初期・王手・打ち歩詰・反復・実局面合計1,033局面等で回帰検査済み。ただし任意の将棋局面で一致の完全数学証明ではない。盤面と履歴の復元を維持。
- **採用対象は高速合法手生成の既定ONのみ**。学習モデル、駒価値、G8相対混合比率、探索上限、RootAlphaBeta、FastMoveList、静止探索、詰み補助は今回の明示採用で変更しない。とくに雲路の実装・研究候補知識は変更しない。

## 正式USIの現行初期値

| 設定 | 初期値 |
|---|---|
| SearchDepth | 4 |
| ValueModelFile | 空（未指定） |
| ValueModelType | legacy |
| ValueModelMix | 50 |
| FastRelativeEval | false |
| RootAlphaBeta | false |
| GuardCheckmate | false |
| FastMoveList | false |
| FastLegalGuard | **true（正式採用）** |

重要：**起動するだけでG8の学習済みモデルがロードされるわけではない**。G8はSHA256 `18b39f647caa458389a1900b875337adadac74ae37e27343e7f0094ed663c492` の研究用モデルで、原本はG8学習run40636602223のartifact。今後G8を公式設定へ昇格するには重みの配布・検証・初期設定を別途明示して仕上げる必要がある。今回勝利を確認した研究条件は、モデルrelative/mix25、深さ上限3、FastRelativeEval/RootAlphaBeta/FastMoveList ON、FastLegalGuard ON、`go movetime 200`。これは初期値とは異なることを明示する。

## 採用の検証と限界

- D12の初期40局：高速15勝・従来8勝・未決着17局。
- 同条件の新しい別seed本検証240局：**高速100勝・従来55勝・未決着85局**。先後ペアの優勢50対21、同数49、両側p=0.0007667649897412907。G8モデル・探索上限3・呼出開始200ms・同一CPU条件で高速合法手だけが差分。全棋譜合法再生とSHA原本監査済み。
- G8同士の改善は示されたが、D13の雲路相手の有効200局では高速ON/OFFとも深路0勝・雲路100勝。雲路の2スレッド・追加長考・先読み等の非対称条件下での実力差は依然大きい。D13の深さ3完了は高速320対従来165で進歩した。
- 多くの200ms呼出に超過があり、厳密な時間保証は未達。別要因として改善する。
- G8モデルファイル未組込、正式USIデフォルト以外の性能向上を未検証のまま実績に加えない。
