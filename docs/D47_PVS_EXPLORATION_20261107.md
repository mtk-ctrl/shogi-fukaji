# D47：深路D45 NNUEを固定したPVS探索・現行探索の300局比較

2026-11-07。**研究専用。正式USIや現行モデルへ自動反映しない。**

## 目的
雲路の探索技術を参考に、深路の「人間の定跡や駒得配点を教えず、自己対局から独創的な勝ち方を学ぶ」という方針に合うものだけ導入する。最初の単独実験は PVS（主変化探索／狭い探索窓での確認と必要時の再探索）。

## 固定事項
- 2陣営とも同一の現行D45 NNUE：研究SHA `941598f2a9ec926d5f67dadf03582ccef718a56a843070dc1f576cc7eeca44e8`、推論SHA `9faf66a9d1fee9d282e35835628377ab7951bb94335a5d0498384bf88f4d2c26`。Adam3794は一切更新しない。
- 現行の `native/nnue_search_ffi.cpp`、正式USI、`formal/model.json`、既存契約・重みを変更しない。
- `scripts/d47_search_compare.py` は、固定された既存C++探索の**1ブロックだけ**をPVS版に置き換え、候補専用の別共有ライブラリとしてコンパイルする。両エンジンは同じC++ルール処理と同じNNUEを使う。
- 全合法手を探索の対象に維持し、狭窓検査で有望ならフルウィンドウで再探索。新しい枝刈り、駒得点、玉の安全配点、外部AI教師、定跡を追加しない。
- 雲路の既存手順をそのまま移植したという主張ではなく、「一般的探索技術を深路で独立に実装」した比較。

## 比較条件を事前に固定
- 過去D43/D45の訓練・評価の4アーカイブから序盤IDを回収し、既出序盤を排除。
- 新規150独立序盤×先後交替＝**300局**。20個の別々のGitHub-hostedランナージョブに14局または16局ずつ割り当て、max-parallel=20。実際の最大同時稼働数と20ジョブIDを確認。
- 同一NNUE・同一CPU種別。1手200ms、両者とも各陣営最大10回の1秒長考、最大512手、静止探索なし、対局中の学習・ランダム探索なし。
- 実局面の固定深さで双方の最善手と評価値が一致することを前検査。失敗なら20ランナーの実対局に進まない。
- 両者の思考時間・探索節点・各指し手・探索方式・終局結果を保存。300局を合法再生し、引分と未決着を分けて集計。未決着を勝ち負けとして扱わない。
- 実棋力を最優先。探索速度・完走深度だけでは採否を判定しない。比較後に分析と本人の正式採用判断を要する。
