# 深路：探索方式と評価方式の分離比較（2026-10-28）

状態：研究候補。**正式採用なし、実戦比較は未起動**。

## 研究の問い

1. **αβ探索の改良**：G8評価モデルと同じ局面・時間で、探索順・枝刈り・前反復の有力手の利用が深さ、節点数、実戦勝率を改善するか。
2. **MCTS（UCT）**：G8評価モデルを固定して探索方式のみ置き換え、αβに勝てるか。方策ネットワークなしの純UCTでは候補手数の多い将棋で探索が浅くなる可能性が高い。
3. **小型NNUE型評価**：探索をαβに固定して、線形G8と増分更新可能な小型ニューラル評価を比較する。既存G8はNNUEではない。実装・学習・200ms速度計測・独立実戦が必要。

## 第1段階：軽量なMCTS研究実装

- `fukaji/mcts_research.py` はUSI本体へ接続しない研究専用関数。python-shogi合法手、現行の `evaluate`、手番視点の価値反転、UCT、時刻・反復上限、盤面復元を使用。
- 詰みは終局として扱う。千日手は探索上の暫定的な罰点であり、対局結果や教師の「引分」ラベルにしない。
- 葉の評価値は `tanh(score / 600)` の**ヒューリスティック**。未校正の勝率確率ではない。方策モデル、プレイアウト、詰みの証明器はない。
- 反復回数固定は再現性検査用。持ち時間比較は実際の反復回数・時間・探索深さを記録し、固定反復数を同じ計算量とみなさない。
- まず単体テストで合法手、先後の符号、履歴と持駒の復元、決定性を確認する。通過しても棋力改善の証明にはならない。

## 第2段階：固定局面の速度・手の差異

- G8/G7対局で用いたモデルと出所をSHA固定し、学習/検証/テストに使った序盤の混入を防ぐ。
- 未使用の独立局面（序盤・中盤・終盤、王手、持駒、千日手寸前を含む）を固定。
- 同じCPU/200msでαβとUCTの合法手、実際の探索節点/反復、経過時間、指し手一致率、詰み対応を比較する。
- 局面の違いだけでは強さを決めない。速度と合法性の明白な劣化があれば重い実戦へ進まない。

## 第3段階：独立先後交替対局

- 事前に比較対象と停止基準を固定。軽量検査とCI通過後、27リポジトリのrunner空き、重複runを確認して20並列×12局＝240局。
- 同じ新規120序盤の先後交替、同じ200ms、同じG8評価モデルを使う。未決着は勝敗/引分に含めず、独立集計する。
- 20分割と集約の22ZIPをSHA照合、全棋譜合法再生、Drive再取得照合、Addnessに事実と物語素材を差分記録。
- MCTS候補が不利なら研究記録に留める。NNUEは探索とは独立して別研究候補として検証する。

## 直前の実測基準

[G8対G7独立240局](https://github.com/mtk-ctrl/shogi-fukaji/actions/runs/40637486947)：G8詰み勝88、G7詰み勝59、未決着93。決着局147局だけのG8勝率59.86%、Wilson95%区間51.79〜67.44%。これは**探索方式の優劣を示さない**。G8研究モデルを正式版へ昇格させない。
