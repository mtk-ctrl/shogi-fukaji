# 深路UCT：生成ノード数とreturn時解放の軽量スケーリング診断（研究専用）

## 目的と前提
総時計ONの非計測12親ABBA（run40723952839）では200ms超過が3/24（最大200.359ms）残った。後続の12反復・計測付き固定3局面の保持対照（PR#75、main9210e1b0）では、根探索木を関数外に保持すると内部／外部時計差が小さくなり、保持解除の時間が差に対応した。関数終了時の探索木解放が軽量条件で主要因だが、前回の非計測200ms超過を完全に説明したものではない。

## 今回の実験
`tests/test_uct_node_cleanup_scaling.py` で、初期・王手回避・持駒ありの固定3局面 × 12/48/96反復 × 根保持OFF→ON→ON→OFF（36呼出し）を調べる。研究専用・既定OFFの既存計測引数だけを使用し、エンジンコード・モデル・既定値・workflowを変更しない。

各呼出しは同一seed、単一合法手走査ON、総時計ON、線形根選択ON、最大深さ4、上限5000ms、固定反復。Nodeファクトリの生成数を記録し、根の子数、最長1反復、内部と呼出側の時計差、保持した探索木の明示解放時間を出力する。保持のON/OFFで選択手、生成Node数、根子数、合法手、盤面復元を確認する。所要時間の大小を合否条件にしない。

**注意**：反復単位の時計計測、根保持、Nodeファクトリの差し替え自体が負荷を加える。12/48/96反復の結果を非計測200msの時間遵守、棋力、正式採用と同一視しない。Node数と解放時間の相関は観測できても、OSスケジューリング・Pythonメモリ管理などがあるため因果や硬い時間保証は別途検証する。
