# 深路G8：戦術局面の原本抽出・研究計画（2026-10-28）

状態：研究準備。**240局原本を使った戦術抽出・αβ対UCTの新しい200ms実測は未実施。正式採用なし。**

## 直前の実測と原因仮説

[G8固定12局面診断](https://github.com/mtk-ctrl/shogi-fukaji/actions/runs/40649711095)は王手中0、持駒あり8、UCTの200ms超過12/12。探索方法による指し手一致は1/12。指し手の相違は強さの証明ではない。

[PR#56](https://github.com/mtk-ctrl/shogi-fukaji/pull/56)はUCTに前反復最大所要時間×1.5（最低3ms）の次反復予約と、王手応手・詰み投了・偽時計検査を追加。1反復の途中停止はないため厳密な200ms保証ではない。実局面での時間超過改善は未検証。

## 本PRの対象

- `fukaji/tactical_positions.py`：SHA固定・全240局合法再生済みの原本を `search_method_probe.load_source` で読み込んだ後に使用する**戦術局面選定部品**。棋譜の実際の合法手を一手ずつ再検査し、棋譜先頭からの着手列とSFENを記録する。
- 詰み、王手中、同一局面3回目（4回反復前）、持駒ありを区別する。棋譜にない分類は「不足」として残し、人工局面で穴埋めしない。
- 分類をまたいでも親ペアは重複使用しない。局面の棋譜履歴・手番・持駒を再構成可能にする。
- **詰み終局は指し手比較から除外し、投了・終局処理だけを比較**する。反復3回目は危険局面の診断であり、勝敗/引分ラベルではない。
- 学習教師の作成、モデル更新、USI正式探索の切替、重い対局起動は行わない。

## 次の実験

1. branch CI→main CI後、全27repoの実行状況を確認し、原本の分類別実在数と欠損を記録する。抽出のための重いジョブは事前に空きと重複を検査する。
2. 実在する戦術局面だけでαβとUCTをG8モデル固定・同じ200msで比較。王手応手・詰み終局・反復・持駒復元・経過時間超過・選択手の合法性を別々に記録する。
3. 200ms超過の改善が確認できなければ原因を局面別に調査する。探索節点とUCT反復数を同一尺度として比較しない。
4. 小型NNUE型評価は別研究とし、αβ固定・親群分離・未決着教師除外で比較する。
