## 手順
1. 雲路の移植元commitとコード/第三者ライセンスの全依存関係を固定する。
2. 合法手・王手・千日手・入玉などのルール層を必要最小限で移植。GPL-3.0の著作権表記、patch、ビルド方法を保持する。
3. USIと自作αβ探索・静的評価を必要範囲で組込み、ビルド・回帰テストを行う。
4. 深路vs深路の同条件200ms自己対局を実行。エンジンSHA、バイナリSHA、先後、seed、開始SFEN、着手、終局事由を保存。
5. 合法性・勝敗を独立監査し、P0学習データ契約へ変換する。ランダム試験生成器と混在させない。
6. 旧版雲路を変更せず、深路単独で再現可能な対局と学習入力の出力を実証する。
