## 1. 分散自己対局

- **現行D43対D43を新規1000局**。20個の独立 GitHub Actions hosted runner × 各10局を5波（各200局）で実行。各wave終了後のみ次波へ進む、有限の自動処理。
- 1手通常200ms、1秒長考は各陣営・各ゲーム最大10回、C++ NNUE・静止探索0・最大512手。新規6手開始序盤、初期24手以内の5%探索用ランダム選択、seed固定。`scripts/d45_games.py` は第1周の実動作済みC++探索・checkpoint手順を再利用。
- 開始序盤親を旧train／旧評価から完全分離。D37保護群、D39/D40、D41自己対局40局、D42比較50親、**D43訓練1000親とD43比較100親**を全部除外。ゲーム開始親の重複禁止。
- 全1000局の合法再生・役割・状態（確定勝敗、厳密な引分、未決着）・親と序盤SHA・実探索時間・1秒長考の回数を検証。全棋譜・plan・ゲーム別SHAを **GitHub Release** に保管し、再ダウンロードSHA一致が成功してから学習開始。

## 3. 棋力判定・採否

- **新しい独立100序盤×先後交替＝200局**。第1周D43の新旧訓練・評価100親、今回の新規訓練1000親、他の旧評価群とは一切重ならない序盤。20独立Actionsランナー、各10局。
- 両者同一C++ NNUE、通常200ms・1秒長考各陣営最大10回、静止探索0。全棋譜合法再生・未決着・時間超過・100序盤ペア単位の統計区間を算出。
- 事前判定：**勝数差12以上、未決着10以下**なら勝ち越し側に実務上の優位があると判定。差が不明なら現行D43維持し追加比較を別途設計。D45学習後が悪化なら不採用。統計不確実性も別記。
