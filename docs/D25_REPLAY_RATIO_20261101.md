# D25：旧経験の保持を同じ更新量で比較する

[D25 Goal](https://www.addness.com/goals/38348d6f-5c15-4988-b8cf-70cb24277eb1)。D24のtrain限定診断から、新経験への適応と旧bootstrapの結果予測悪化が併存した。旧経験の再生割合不足を一要因で調べる。既学習棋譜上の改善を棋力改善と呼ばない。D24固定400局の完了前に学習しない。

## 凍結する実験

- 親は第14周2161b2ba、optimizer1300。正式モデル・研究latest・固定anchorは変更しない。
- 最近は第12〜14周の11決着局。旧経験はbootstrap665＋第1〜11周42決着局＝707局。重複と未決着を除外し、monitor/audit親は入口で拒否する。
- 勝敗75%＋凍結親TD(λ=.8)25%の教師と各局32位置以下の共通poolを一度作る。両側が同じpool/ラベルを使う。
- 最近:旧を50:50と25:75で比較。pool内の抽出位置を復元抽出し、各側1024サンプル、2epoch、128batch、lr=.001、追加16optimizer stepsを一致させる。ratio以外の総学習量は揃える。
- 共通seed202611012500/501/502の3反復、全6モデルを保存し、全seedを報告。都合の良いseedを選ばず、対局へ進む代表は事前に500末尾seedと固定する。
- 旧と新の保持診断はD24と同じtrain抽出ルールで両側を測る。補助指標BCE/Brierは新しい棋力試験と区別。

## 判定と次工程

旧経験の損失を下げても最近経験が大きく悪化するなら単純な比率変更では足りない。3seedの保持傾向を全件示し、比率差を機序の診断として扱う。棋力の判断が必要な候補は、新しい独立序盤でモデル・条件・局数を先に固定した対局へ進める。4局の勝ち越しで強化成功を認定しない。D24と同じ目的なら100序盤の先後200局を一比較に用い、標本幅は約±13.6pt（未決着幅は別）。D24の100親は再利用しない。

この実験は、現行サイクルの50:50を全棋譜学習へ変える際にoptimizer更新回数も増えてしまう交絡を避ける。総pool位置数と抽出位置の重複率を保存し、短い終盤からの新経験の偏りは別課題として残す。

## 実行時の比較対象

第14周から分岐した代表seed202611012500の2候補を比較する。候補は最近25:旧75、対照は最近50:旧50。第14周そのもの・第11周・初回基準との比較ではない。両側は同じ新旧train pool・教師・追加16stepを共有し、研究pointerは第14周のまま。3seedの学習完了を確認後、成績で選び直さず代表を凍結する。

新しい100序盤組の先後200局、双方C++/q0/100ms/総512手、単一比較。Hoeffding区間は序盤組単位、alpha.05で標本幅±13.581pt（未決着幅別）。最終endpointだけで判定する。D24の親と重ならない。

明示candidate/opponentsを受け取る評価経路を追加したが、D24の400局が完了し全棋譜再生を通った後に変更した。実候補を試験してもresearch_latestを変更せず、開始時のpointerと履歴を別に凍結して再開検証する。実workerの追加検査でこの非変更を確認した。

## 同じ更新量の学習と保持診断

全6候補が各1024sample・optimizer1300→1316で完了。両arm同じモデルから開始し、同じ実勝敗でのtrain限定診断を全候補へ実施した。以下は局ごと等重みのBCE（小さいほどよい）。

親第14周は同じ順で .509576 / .552723 / .559148。3seed全てで75%側のbootstrap保持は50%側より良く、最近経験への適応量は50%側が大きい。過去自己対局群では50%側が少し良い。旧経験比率は一律の改善を生むわけではなく、分布間のトレードオフが見える。学習済みデータ上の結果なので、棋力向上とは認定しない。

事前指定seed500のモデルは、最近25:旧75が413ccd57、最近50:旧50がa8292e37。全seedの候補は保持し、成績による選び直しをしない。この2モデルの新100序盤・先後200局をd25-replay200として凍結する。

## 比率の単位と経験の偏り

従来cycleの50:50は**棋譜数**で、D25の50:50/25:75は**共有poolから抽出した位置数**。D25の50%側は従来cycleの完全再現ではない。2armの間では比率以外を揃えているが、その結果をそのまま従来更新全体との優劣に置換しない。

過去14周のmanifestと同じseed/隣接位置抽出を再構成し、各周のpositions総数が保存済みtraining.positionsと一致することを確認。直近12〜14周の旧位置割合は51.05%、48.37%、56.86%。14周で再生対象になったbootstrapは665局中52局、7.82%に限られ、各周の新しい経験も2開始親。比率と別に、学習対象の多様性・旧経験カバー率が次の課題になる。これはtrain記録とmanifestだけの診断で、対局の途中成績を次の学習へ流していない。

## 固定200局の結果

事前指定seedの最近25:旧75候補413ccd57が、最近50:旧50候補a8292e37へ**102勝94敗2分2未決着**。100新序盤の先後200局、全33,294手の合法再生と終局結果一致。実行858.152秒、事前planからの総経過876.498秒（初期保存等を含む）。未決着を確定させない全局得点は51.5〜52.5%、事前Hoeffding区間は37.919〜66.081%、判定は**未確定**。

3seedでのbootstrap保持差は再現したが、この代表seedの対局で旧75%側の優位は確定しない。旧75%候補を研究latestへ移さず、研究親は第14周2161b2ba/optimizer1300のまま。2候補は第14周そのものに対しては未比較であり、今回の勝ち越しを第14周超えに置換しない。全6候補、共通pool、schedule、棋譜は保全。

次は[D26](D26_EXPERIENCE_DIVERSITY_20261101.md)で、1更新の新しい開始親2→16、train局4→32へ広げた有限1周を実行する。保持比率だけの細かな調整より、経験の多様性を優先する。少数故障screenを安定強化とは呼ばない。
