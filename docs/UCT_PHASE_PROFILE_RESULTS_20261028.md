展開工程には `board.is_checkmate()`、`board.is_fourfold_repetition()`、`list(board.legal_moves)`、子ノード生成、着手処理が含まれる。したがって「合法手生成だけが98%」と結論しない。次はこの複合工程を王手/詰み判定、反復判定、合法手列挙、子生成、着手へ分割し、同じ親6/11で再計測する。
