## 起動とUSI

検証対象はLinux x86_64、Python 3.12、g++（C++17）。`python3 -m pip install -r requirements.txt` の後、`chmod +x run-fukaji.sh`、GUIに `run-fukaji.sh` を指定する。別ディレクトリから起動できる。初回isreadyでC++共有ライブラリをコンパイルし、`build/native-nnue/`へ保存する。Windows向け実行ファイル/APKは今回の配布対象ではない。

対応：usi/isready/setoption/usinewgame/position/go/stop/gameover/quit。startpos/sfenと全movesを保持し、千日手・連続王手の履歴を探索へ渡す。非法手・終局後着手は拒否する。先後同一局の履歴伸長は差分反映し、新しい局面系列は探索状態を作り直す。stopはC++のatomicフラグで探索を中断し、bestmoveを1回返す。新position/quitで旧探索結果を破棄する。

`go movetime N`、btime/wtime/byoyomi/binc/winc、depthに対応。時計配分は残り時間/30＋秒読み＋加算を基本とし、残り時間＋秒読みから10msを差し引く。探索予算は1〜10000ms。`go depth N`単独は深さ固定の解析で時計制限を課さない。`go infinite`は最大10秒探索後にstopまで待機する有界解析。厳密な壁時計上限を保証する設計ではなく、極短時間の通信・局面同期等の超過はあり得る。`go mate`はnotimplemented、ponderには対応しない。

## 現行モデルの採用判断と強さの不確実性

[D43採用記録](decisions/2026-11-07_D43学習後モデルを現行に採用.md)により、学習後D43（`bf8c26f9f8f6adff8a87c46ab04fcf5cd76a7915be241da11b99bb4ae2ac8b9f`、Adam2882）を現行NNUEとする。D37からの新規自己対局1000局、旧train665局のreplay、2epoch追加学習。新規100序盤先後交替200局（200ms＋各陣営1秒長考10回）でD43は**150勝50敗、引分0、未決着0**。実際の棋力向上の根拠は学習lossではなくこの対局結果。ただし他環境・他時間制御の勝率を保証するものではない。原棋譜と比較条件は[GitHub Release](https://github.com/mtk-ctrl/shogi-fukaji/releases/tag/fukaji-d43-d37-before-after-200games-42292240321)に保存済み。

`benchmarks/baseline_ref.txt` の固定比較基準は変更しない。次のNNUE自己学習は現行D43（Adam2882）のGitHub保存済み完全stateから開始し、更新前snapshotと更新後を同条件で対局比較する。改善確認後に新しい現行モデルとしてmanifestを更新。失敗・悪化時は更新前D37へ戻す。D37の過去研究stateを現在の学習起点へ昇格するのは、今回本人が明示した一回限りの切り替えであり、今後は独立研究候補系列を作らない。
