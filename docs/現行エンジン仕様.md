# 深路（FUKAJI）現行エンジン仕様

更新：2026-11-03。正式版は **FUKAJI v0.3.0**。オーナーの明示指示によりD33代表NNUEを採用した。強さ比較は採用時点で未実施であり、棋力向上の実証を意味しない。正式入口は `python -m fukaji.engine` または `run-fukaji.sh`。深路固有の版であり、雲路の実装・モデルは変更しない。

公開manifestは `formal/model.json`。研究snapshotから推論用のw/b/v/oだけを取り出し、全テンソルと出力バイアスを一致確認する。Adamや棋譜は正式推論に不要なので同梱しない。重みは本人限定の起動パッケージに同梱する。公開リポジトリ単独には学習済み重みを置かない。

`isready` 時にファイルSHA・形・有限値を確認してからC++へ登録する。欠損・破損・別モデル・ビルド失敗時はERRORを出して終了コード2、readyokを返さない。旧評価やランダム重みへの代替はしない。`NNUEFile` は同じ採用ファイルの配置変更用であり、別SHAの研究候補は受け入れない。相対パスはエンジン配置ディレクトリから解決する。

## 起動とUSI

検証対象はLinux x86_64、Python 3.12、g++（C++17）。`python3 -m pip install -r requirements.txt` の後、`chmod +x run-fukaji.sh`、GUIに `run-fukaji.sh` を指定する。別ディレクトリから起動できる。初回isreadyでC++共有ライブラリをコンパイルし、`build/native-nnue/`へ保存する。Windows向け実行ファイル/APKは今回の配布対象ではない。

対応：usi/isready/setoption/usinewgame/position/go/stop/gameover/quit。startpos/sfenと全movesを保持し、千日手・連続王手の履歴を探索へ渡す。非法手・終局後着手は拒否する。先後同一局の履歴伸長は差分反映し、新しい局面系列は探索状態を作り直す。stopはC++のatomicフラグで探索を中断し、bestmoveを1回返す。新position/quitで旧探索結果を破棄する。

`go movetime N`、btime/wtime/byoyomi/binc/winc、depthに対応。時計配分は残り時間/30＋秒読み＋加算を基本とし、残り時間＋秒読みから10msを差し引く。探索予算は1〜10000ms。`go depth N`単独は深さ固定の解析で時計制限を課さない。`go infinite`は最大10秒探索後にstopまで待機する有界解析。厳密な壁時計上限を保証する設計ではなく、極短時間の通信・局面同期等の超過はあり得る。`go mate`はnotimplemented、ponderには対応しない。

## 採用判断と強さの不確実性

D33代表候補 `e0cbd2ab...`（親 `c8ad43bf...`、Adam1708）を、オーナーの明示指示により正式採用した。予定していた新100序盤×先後200局の比較は採用時点で0局であり、強さ比較は未実施。したがって、この正式採用は棋力向上が実証されたという意味ではない。D33比較は別途、凍結済み条件で継続する。比較の実測結果が出たら本仕様を追記する。旧正式版v0.2.0の重み・配布物・コード履歴は保全する。

## 復元・研究との境界

旧v0.1.0のPython USIは `python -m fukaji.engine --legacy` で実行でき、FastLegalGuard既定true、旧オプションを保持する。[旧仕様](archive/2026-10-31_v0.1.0_エンジン仕様.md)と `formal-contract-v010.json`、旧正式コードcommit `364b2645797d436e531a28b0b5013a6cc70bfbe1` を保全する。旧研究workflowは--legacyを明示し、過去の比較をNNUEへ置き換えない。

`benchmarks/baseline_ref.txt` の固定比較基準は変更しない。NNUE重みは現行正式版から直接学習し、学習前snapshotとの直接対局で強化を確認できた更新後重みを正式版manifestへ反映する。失敗・悪化時は学習前重みへ戻す。過去のresearch state/latestは旧実験の履歴として保全し、今後の正式NNUE更新元には使わない。
