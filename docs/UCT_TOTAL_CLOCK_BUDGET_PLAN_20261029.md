# 深路UCT：関数呼出し全体の時計予算（研究候補、2026-10-29）

## 目的と前提

[時計境界監査](UCT_CLOCK_BOUNDARY_AUDIT_20261028.md)で、48観測の呼出側200ms超過13件に対し探索内部の200ms超過0件を確認した。内部時計の開始前に根合法手列挙と根ノード準備が存在する。差分全額の原因帰属は未実測。

本候補は `fukaji/mcts_research.py` の `total_budget_from_call=True` の場合だけ、関数冒頭から `time.monotonic()` で計時し、引数検査、根合法手列挙、根準備、反復を**同じ予算**に含める。既定は `False` のまま。雲路main、深路既定USI/モデル、研究の正式採用を変更しない。

## 安全上の制約

- 根準備だけで予算が尽きた場合は、反復0回で最初の合法手を返す。合法手なしの場合は投了する。反復0を詰み・勝利・引分と誤認しない。
- 盤面SFENと着手履歴の復元、王手・詰み・打ち歩詰・千日手・持駒の既存回帰を維持する。
- Pythonの一反復、根合法手列挙、OSスケジューリングは中断不能であり、**厳密200ms上限は保証しない**。
- 合成時計で根準備12ms＋評価10msを作り、既定内部時間10ms／候補全体時間22msを検査する。根準備50ms・予算20msでは反復0、合法手を返す。これは実局面速度や棋力の証明ではない。
- `single_pass_legal_moves` と独立した任意フラグ。既定OFF。新たな学習・対局・外部送信はしない。
