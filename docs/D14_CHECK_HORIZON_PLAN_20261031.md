# D14：王手中の探索末端を1手だけ延長する研究（2026-10-31）

## 課題の実測根拠
- 正式USIは v0.1.0（FastLegalGuard既定ON）。D12独立240局で高速版100勝・従来版55勝・未決着85局、ペア符号検定p≈0.00077。
- 一方、D13修正版200局（run41184685991）では、雲路相手に旧G8も高速G8も100局全敗。高速版の深さ3完了数320/2,271回、旧版165/2,162回。読みを速くしても王手・詰みへの対応が十分とは限らない。
- 過去100局の最終防御手サンプル20局では5局が即詰み回避可能、15局はその手番では全合法手で即詰み。「最後の1手」より前に脅威を読む質が問題。
- 以前のD3静止探索を全面的に加えると、G8/200msでは深さ完了が退行したため、そのまま復活させない。

## 単一の改善仮説
通常の深路は探索の深さ0で静的評価へ戻る。そこで、**深さ0で手番側が王手されている場合に限り**、全合法な王手回避を1手ずつ調べてから静的に比較する。全合法手・成り・打ち歩詰・王手による応手制限はpython-shogiの合法性に従う。

- OFF：現行v0.1.0（深さ0で即静的評価）。
- ON：同じv0.1.0＋`leaf_check_evasion=True`。既存のG8モデル・時間・高速合法手・深さ上限3・αβなどはOFFと一致させる。
- 一手だけで打切り、連続王手を無限に伸ばさない。実時間の期限を超えそうな場合は探索反復を中断し、未完成を評価値として偽装しない。結果は「王手を受けた時の合法応手を1手加えた限定評価」であり、勝ち・不詰みの証明ではない。
- **正式USIの既定値・メニューに本研究用フラグは追加しない。** 実測で有望でも別seed実戦40局→必要なら240局を経て本人の正式採用判断を得る。
