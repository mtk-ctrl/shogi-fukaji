## D4第1工程：証明器と反例
- 研究用 `fukaji/mate_oracle.py`。全合法な初手のうち王手を掛ける手だけを調べ、守備側の全合法応手を列挙し、**すべての応手**について合法な1手詰みが少なくとも一つあるときだけ3手詰みとする。応手が0なら別の1手詰みとして分類。王手以外・合法応手の未調査・長考一致は証明にしない。
- `max_legal_moves` の上限を超えた場合は `ProofIncomplete` として**不明**。不詰みや負けとはしない。着手のpush/popは例外時も復元。python-shogiの反復辞書はpop後に0回のキーを残すため、SFEN/着手履歴/正の反復回数で実効状態を照合する。
- 人工局面 `8k/9/7R1/7L1/9/9/9/9/8K b - 1` では1手詰み4手（`2c1c`、`2c1c+`、`2c2a+`、`2c2b+`）。これとは別に**3手詰みの強制手順** `2c2a` → 守備側の唯一の合法応手 `1a1b` → `2a2b+` を全合法手列挙で発見。検査時の初手23、守備応手1、検査した合法手51。
- 香を除いた `8k/9/7R1/9/9/9/9/9/8K b - 1` は1手詰み0、`2c2b+` 後に守備玉の `1a2b` が合法。初期局面は1手/3手詰み0。上限1手では `ProofIncomplete` を出し、局面を復元する。
- 以上は**人工局面の開発用有界証明**であり、独立した未見問題・3手詰み正答率・G8選択手・実戦勝率の証明ではない。探索本体への自動接続、教師化、正式採用なし。雲路main変更なし。
