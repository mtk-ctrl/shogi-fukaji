## 目的と既存事実
総時計ON・単一合法手走査ONの固定12親ABBAでは、外部呼出し200ms超過3/24（200.121、200.359、200.039ms）、内部計時超過0/24。外部−内部の差は中央値2.040ms、最大2.796ms。原本とSHAは `docs/UCT_RETURN_CLOCK_RESIDUAL_AUDIT_20261029.md` に固定。残存超過の直接原因は未確定。

`select_mcts` は内部経過時間を算出した後に `return best.move.usi(), iterations, elapsed` を実行する。Pythonの関数フレームが終了すると、保持していた根・子ノード群の参照が解放される。**関数内部で経過時間を読んだ後の探索木の解放処理が、呼出し側の計時には含まれる**可能性がある。これは既存の「時計境界・最終手選択」とは別の検証仮説であり、まだ実局面での因果確認はない。
