# 深路UCT：戻り際の探索木解放と時計差の軽量診断（研究専用）

## 目的と既存事実
総時計ON・単一合法手走査ONの固定12親ABBAでは、外部呼出し200ms超過3/24（200.121、200.359、200.039ms）、内部計時超過0/24。外部−内部の差は中央値2.040ms、最大2.796ms。原本とSHAは `docs/UCT_RETURN_CLOCK_RESIDUAL_AUDIT_20261029.md` に固定。残存超過の直接原因は未確定。

`select_mcts` は内部経過時間を算出した後に `return best.move.usi(), iterations, elapsed` を実行する。Pythonの関数フレームが終了すると、保持していた根・子ノード群の参照が解放される。**関数内部で経過時間を読んだ後の探索木の解放処理が、呼出し側の計時には含まれる**可能性がある。これは既存の「時計境界・最終手選択」とは別の検証仮説であり、まだ実局面での因果確認はない。

## 予備的な独立合成実験（本番環境ではない）
Python dataclass Nodeとchildrenだけの単純な木を作り、関数内部の時刻取得直後に戻る場合と、呼出し側へ根を保持してから明示的に解放する場合を50回ずつ比較した。ローカル環境、GC無効、中央値。

## 軽量固定局面検査
`tests/test_uct_return_cleanup_probe.py` は初期・王手・持駒の3固定局面、各12反復、同seed、同一合法手走査・総時計・線形根選択を使用。根の参照を呼出し後まで保持しない/保持するABBA各2観測、計12呼出し。保持のON/OFF以外は同じNodeファクトリを通す。任意の `clock_phase_trace` で根準備・反復・盤面復元検査・最終手選択・内部時計境界を出力し、関数外計測との差と明示的解放時間をログに残す。固定反復の着手一致・合法性・盤面復元・根参照数を検査する。**計測による負荷と保持処理があるため、非計測200msや棋力との比較に使わない。** 速度の優劣をテストの合否条件にしない。
