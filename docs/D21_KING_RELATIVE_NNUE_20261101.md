# D21：玉相対NNUEの同一経験比較

2026-11-01。[D21 Goal](https://www.addness.com/goals/d65918a9-26ea-4fc0-a100-7aa8d53d5d5f)。元状態はD20の本人限定完全状態。正式版の採用変更は行わない。

## 狙いと実装

従来NNUEは駒種・所有者・絶対升と持駒の2548入力。自玉・相手玉から各駒への相対位置を加え、攻撃/防御に必要な位置関係を自己対局勝敗から学べるようにする。手作業の局面配点や外部評価値は導入しない。

追加は2玉anchor×2所有者×玉以外13駒種×17×17変位の15028入力。合計17576入力、隠れ32のまま。持駒と従来の絶対位置は保持。白視点は180度回転して所有者を入れ替える。玉が欠ける診断用局面は、そのanchorのみ省略する。合法性は将棋ルール側で判定する。

第11周親ac2d9c51の重み・Adam moment/step1288を引き継ぎ、新規行の重みとmomentだけゼロ初期化。旧部分と相対部分を別々に集約し、拡張直後の評価を元親と一致させる。玉の移動時は両視点を再構築し、それ以外は動いた駒の絶対・相対特徴と変化した持駒のみ差分更新。undoは保存済みaccumulatorを復元する。

保存schemaは従来v1と新king-relative-v1を区別し、shape・schemaを照合。旧snapshotとoptimizerを読める状態を維持する。研究用探索のみで使い、正式USIは変更しない。

## 一要因比較の事前条件

- 親、optimizer年齢、経験、抽出位置、凍結親のTDラベルを固定。
- 直近3周の決着12局＋bootstrap trainから固定seedで52局、合計64局。monitor/auditは学習に使わない。
- 75%実勝敗＋25%凍結親TD(lambda=.8)、2epoch、lr=.001、同一batch順、seed202611012100。
- 両候補のラベル全要素と、抽出した旧特徴列が同一であることを実行中にassertする。
- 学習前に上記trainから24局面、元親対ゼロ拡張の深さ2探索を比較。着手・評価と速度を記録する。
- 新8序盤・先後16局、100ms指定、最大256追加手。拡張型対同じ条件で追加学習した従来型。実時間、節点、深さも保存。指定時間の厳密上限とは扱わない。
- 未決着を引分/勝敗教師へ変換しない。研究pointerを勝ち越しだけで自動変更しない。今回の候補と元親を保存する。

## 64局学習の結果と続行判断

新8序盤の先後16局、321.077秒。玉相対型 **3勝8敗2分3未決着**。全16局2858手を合法再生し、終局結果一致。候補は元親を置き換えない。

指定時間の厳密上限は未達。BCEは決着したmonitor対局を16手間隔で抽出した診断値で、最終試験ではない。未決着の勝敗ラベルは作らない。

相対15028行のうち3610行に学習履歴。対局中の相対特徴は標本平均95.76%が学習済みだった。未知入力だけを原因と断定できず、train適合改善が対局の汎化改善へつながっていない。速度低下もあるが、勝敗の原因をそれだけに断定しない。
