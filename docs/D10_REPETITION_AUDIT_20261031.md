# D10：反復回避による候補除外の診断

強化目標は継続的な棋力向上。一つのPR・CI・実験結果の保存を研究全体の終了としない。本人の2026-10-31「残るのはって何？ 強化はずっと続けないと」を受け、一部の停止箇所を研究全体の停止条件へ広げない。

## 仮説と目的
現行select_moveは、探索前に各合法手の遷移先の出現回数を数え、最小の回数の手だけを探索する。これが反復を減らす一方で、必要な受けや有利な手を除外していないかを調べる。探索内部にも2回目の局面を-1000点とする処理があるため、rootの除外を単純にOFFにすれば強くなるとは仮定しない。

PR132のD9時計確認比較は未統合・未起動。その説明値訂正の拒否を別経路で回避しない。D10はmainに既存のavoid_repetition引数だけを比較し、D9の未統合コードや拒否対象ファイルを変更しない。通常USI・既定値・正式モデルは変更しない。

- 20分割×12局、各局で最初にroot候補の除外が起きた局面を1つ選ぶ。勝敗やその後の指し手を選別条件にしない。全240局の全手の合法再生は最後まで実施するが、除外発生の走査は最初の対象までとする。
- 同じrunner・同じ履歴・同じ固定G8/mix25・高速相対評価/単一走査/root alpha ON。深さ2を双方とも完了させ、反復除外ON→OFF→OFF→ONのABBA。時間競争やD9時計変更を混ぜない。1呼出5秒超・深さ未完了・履歴不復元・非合法手は故障として停止。

## 結果から続ける作業
1. 除外ONだけが1手詰みを許す実例があれば、その合法履歴を再現して受け候補を残す研究用修正へ進む。
2. 単純OFFが反復手を選ぶ場合は、内部の反復評価の視点・符号と四fold終局の扱いを切り分ける。勝敗や千日手の規則を推測で変更しない。
3. 問題が見つからなければ、この除外方式が安全と断定せず、調査範囲と限界を保存して別の評価・戦術候補へ進む。
4. 候補実装は既定OFF・回帰試験後、新seedの40局→独立240局で棋力と実時間を比較する。D8診断群を最終採否群に転用しない。

実観測の詳細は30日期限の診断artifact。選ばなかった候補手を長期の実戦手教師へ混入させない。技術正本には出所、集計、判定、次の実作業を保存する。実在の長い待ちだけ、実測の終了見込みに同じ単発タイマーを置く。
