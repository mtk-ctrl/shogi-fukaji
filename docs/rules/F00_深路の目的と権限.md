# 深路の目的と権限

2026-10-31の本人依頼に基づく深路固有Rule。雲路のRule一式を自動継承しない。

- 最優先は実際の棋力と長期的な棋力向上。続いて有効な学習量/時間、信頼性、探索効率、保守性。実験数・文書数は手段。
- 深路は自己対局の経験からNNUEで価値判断を獲得する。雲路の手作業配点・重み・研究手・局面知識、外部AIの評価値・推奨手・PVを教師にしない。実戦手の記録と正解教師への利用は別。
- 一般的な探索・合法手・時間管理の技術は調査できる。雲路を参照しても深路で独立実装・比較する。今回のルーティング修正を除き雲路本体・設定は変更しない。
- 本人の2026-11-04明示指示により、NNUEの学習と採用は同じ正式版の学習前後比較で行う（[決定記録](../decisions/2026-11-04_正式版起点NNUE学習.md)）。以前の「正式版を固定し、別の研究候補を育て、正式採用はさらに本人判断とする」運用をNNUE重みに適用しない。
- 各周は現行正式版の重み・学習状態から直接継続する。開始前の重みは比較・復元専用の不変snapshotとして保持し、独立した研究候補モデルとして管理しない。
- 学習後重みを学習前の正式版snapshotと、事前に定めた同条件の対局で比較する。比較計画に照らして強化を確認できたら正式版重みを更新し、次周はその重みから続ける。明確な改善が確認できない場合は正式版を維持し、必要な追加比較を行う。統計的有意差を一律の採用条件にしない。
- NNUE重みのこの更新サイクルは本人の指示により比較通過後に正式採用可能。探索コード・正式USI・版名・配布形式などNNUE重み以外の正式仕様変更は別途明示指示後に行う。
- `benchmarks/baseline_ref.txt`等の固定評価基準・学習データ境界は維持し、正式版前後比較に流用して汚染しない。
- 合法性、データ出所、評価群保護、成果物保全を速度のために省略しない。未実施・失敗・未確認・暫定判断・実証済みを区別する。
- 課金追加、外部公開投稿、無制限の常時運転の許可を推定しない。

根拠：[今回の判断記録](../decisions/2026-10-31_高速自己学習サイクルと正式採用の分離.md)。

## 「現行モデル」の意味と2026-11-04のD37切り替え

本人は「正式版」という抽象的な承認階層を求めず、**今の最強として選定して使う重みを「現行モデル」**と呼ぶ。学習直前に保存する不変の重みは「更新前モデル」、自己対局から学習した重みは「学習後モデル」と呼び、直接対局して改善を確認できれば学習後モデルを新しい現行モデルにする。旧「正式版」は歴史的な旧称であり、新たな独立研究候補系列を保持する理由にはしない。

2026-11-04の**本人の明示判断により、旧比較の勝ち越しを根拠にD37最終重み(170d6c1e、Adam2106)を現行モデルに採用**。F00/F20の通常の学習前後直接比較とは異なり、旧研究成果を基準に据える初回一度の移行判断。200ms＋長考10回の棋力比較が採用前に完了したという意味ではない。以後は現行D37から直接学習して更新前後を直接比べる。[決定](../decisions/2026-11-04_D37を現行モデルに採用.md)を正本とする。

## 独創性・定跡禁止・詰み探索（2026-11-07本人の最優先コンセプト）

2026-11-07の本人の明示判断により、**深路はAlphaGo Zero / AlphaZeroに近い「人間の定跡に縛られず、ルールと自己対局から勝ち方を発見するAI」を目指す。これは全研究・実装に優先して守る原則。** 初期AlphaGoにあった人間の棋譜による教師あり学習を採用するという意味ではない。出所・理由・境界は[決定記録](../decisions/2026-11-07_深路の独創性と詰み探索の原則.md)。

- **禁止**：人間の定跡・戦法・囲い・手筋を模倣させる学習、定跡書・人間棋譜・他エンジンの推奨手／評価値による正解教師、固定された駒得／玉攻め／悪形への人手配点、定跡に反する合法手の禁止。**捨駒や常識外の一手も探索候補に残す。**
- **必須**：合法手・王手・受け・千日手・**詰み**などゲームのルールを厳密に扱う。詰み1手の合法全探索、続く3手・5手などの強制詰みの読みと王手への全合法応答検証は、定跡や棋風の注入ではなく勝利条件を正しく計算するために進める。
- **許容**：正しい先読みを実現する一般的な探索技術、時間管理、探索木・方策／価値ネットワーク、実際の自己対局結果による強化学習。静止探索等は定跡教師ではないが、取り手・捨駒を不当に排除しないよう探索品質を検証する。
- **禁止事項の区別**：確率的探索や初期重みの乱数は認めるが、合法手から**ただ一様乱数で選んだ手を「独創的」と評価しない**。まず将棋の初期局面から自己探索し、探索的な多様性と本当に勝てる新手を区別する。
- **棋力の判定**：学習前後の対局勝率に加え、ルールから生成した詰み局面の解決率・実棋譜の明白な詰み見逃しを別検証する。定跡に近い・離れたという審美基準で採否を決めない。
- 現行D43／Adam2882および進行中D45 run 42326260509の条件を変更しない。このRuleは次の研究の**判断基準**を更新するもので、探索コードやUSIの正式仕様を勝手に変更する許可ではない。
