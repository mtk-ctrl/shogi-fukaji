# NNUE学習とデータ境界

- 勝敗は局面の期待結果を学ぶ観測値であり、全着手の最善性を認定しない。勝ち側・負け側の両方を手番基準で学ぶ。
- 確認済み勝敗・厳密な引分・未決着・障害を区別する。手数打切りを引分や敗北に置換しない。現在のD17は詰み・連続王手の負け・通常千日手だけを結果教師とし、未実装の入玉等は未決着のまま扱う。
- 初期学習はSHA・親分割を確認した自己対局trainだけ。旧G8 validation/test、D6の評価専用400局、他の評価群を訓練へ転用しない。
- train/monitor/auditの役割は結果を見る前に固定。同じ開始親の先後ペア・再開局は役割を継承。monitorは反復する開発比較であり未見最終試験ではない。正式採用判断用auditは別の新しい親群・固定条件で一度だけ評価する。
- 学習入口は自己生成trainと検証済みbootstrapの許可リストに限定。外部ファイルのrole/source自己申告だけを利用許可にしない。
- 開始局面・実戦手・終局根拠・親ID・モデルID・設定・seed・欠損を保存。PVや探索木を永続的な正解教師にしない。
- 時間差分の目標値は凍結親モデルで計算し、同じ更新の勾配を教師へ流さない。実結果を主成分とし、結果だけの対照を用意する。
- 新旧経験を混ぜ、最近の失敗を修正すると同時に忘却を監視。使わなくなった原棋譜も消さない。
- モデル・optimizer・親子関係・データ・seed・学習率・更新回数・損失を記録。損失低下だけで棋力向上を主張しない。

具体値：[D17計画](../D17_FAST_SELF_LEARNING_20261031.md)と実行manifest。
