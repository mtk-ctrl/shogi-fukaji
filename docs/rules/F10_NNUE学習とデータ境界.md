# NNUE学習とデータ境界

- 勝敗は局面の期待結果を学ぶ観測値であり、全着手の最善性を認定しない。勝ち側・負け側の両方を手番基準で学ぶ。
- 確認済み勝敗・厳密な引分・未決着・障害を区別する。手数打切りを引分や敗北に置換しない。現在のD17は詰み・連続王手の負け・通常千日手だけを結果教師とし、未実装の入玉等は未決着のまま扱う。
- 学習の親はその周の開始時点の正式版NNUEとする。別の研究候補から学習を始めない。学習前の正式版重みは不変の比較・復元snapshotとして保存し、学習後重みを同じ相手として直接比較する。対局結果に基づき強化が確認できれば学習後重みを正式版として更新し、次周の起点にする。強化が確認できない場合は学習前正式版へ復元する。
- 初期学習はSHA・親分割を確認した自己対局trainだけ.旧G8 validation/test、D6の評価専用400局、他の評価群を訓練へ転用しない。
- train/monitor/auditの役割は結果を見る前に固定。同じ開始親の先後ペア・再開局は役割を継承。monitorは反復する開発比較であり未見最終試験ではない。正式採用判断用auditは別の新しい親群・固定条件で一度だけ評価する。
- 学習入口は自己生成trainと検証済みbootstrapの許可リストに限定。外部ファイルのrole/source自己申告だけを利用許可にしない。
- 開始局面・実戦手・終局根拠・親ID・モデルID・設定・seed・欠損を保存。PVや探索木を永続的な正解教師にしない。
- 時間差分の目標値は凍結親モデルで計算し、同じ更新の勾配を教師へ流さない。実結果を主成分とし、結果だけの対照を用意する。
- 新旧経験を混ぜ、最近の失敗を修正すると同時に忘却を監視。使わなくなった原棋譜も消さない。
- モデル・optimizer・親子関係・データ・seed・学習率・更新回数・損失を記録。損失低下だけで棋力向上を主張しない。

具体値：[D17計画](../D17_FAST_SELF_LEARNING_20261031.md)と実行manifest。

## 現行D37を起点とする学習（2026-11-04本人判断）

「正式版」は今後の説明では**現行モデル**。現在はD37最終NNUE(170d6c1e)、Adam2106。これを学習前に不変保存し、新しい自己対局/合法再生検査済みtrainと、既存の許可済みtrainのreplayを使って直接学習する。学習後の状態は別系統の研究最新版ではなく現行モデルの**学習後の一時状態**。比較未完了・悪化時は現行D37を保持する。初回4局の結果とAdam2112の学習後snapshotは[D39](../D39_CURRENT_D37_SELFPLAY_REINFORCEMENT_20261104.md)、学習後の強さは未判定。旧D36やe0へ起点を戻さない。

## 人間の定跡を教師にしない・勝敗と詰みを区別する（2026-11-07）

[F00の最優先コンセプト](F00_深路の目的と権限.md)と[本人の判断](../decisions/2026-11-07_深路の独創性と詰み探索の原則.md)を継承する。**定跡／人間棋譜／他AIの指し手を模倣する教師、手作業で「良い手」を規定した報酬・評価値を追加しない。** 合法手・勝敗・詰み・千日手などのルール事実は、外部の人間知識ではない。自己対局結果や、現行モデル自身の探索が生成した方策／勝率の学習は、評価群との混合を避けて条件付きで研究できる。

**勝った側の全手を最善手とはみなさない**。詰みの見逃しは結果教師だけでは修正しにくいため、合法手と詰み判定から独立に計算した探索テストで確認する。負け局面での捨駒や非定跡手を教師の都合で禁止しない。既存のD45 train／audit の分割・結果は凍結のまま保全する。

## 詰み専用の外部局面例外（2026-11-07本人判断）

上記の「自己対局trainのみ」「外部ファイルを学習へ取り込まない」の制約は、**一般局面の優劣を学ぶ正式NNUEの価値学習**に引き続き適用する。他方、外部の**詰将棋盤面（SFEN）のみ**を、合法手から深路自身で詰み／不詰／不明を証明する研究、詰み専用の補助器学習、専用ベンチマークへ利用してよい。外部のファイル分類に詰み手数ラベルがある場合はその出所を明示し、必ず合法な全応手で独立検証し、未証明の「不詰」ラベルを作らない。

雲路の自作詰み探索や予測器の再利用は、**詰みの証明とその探索優先に限る**。人間棋譜や他AIの評価・手の模倣を正式NNUE教師へ混入しない。研究用局面と、改善の採否を測る未見固定局面を親ID/SFENハッシュで分ける。出所と再配布条件を確認する。詳細は[F00](F00_深路の目的と権限.md)と[詰み専用利用の決定](../decisions/2026-11-07_外部詰将棋局面と自前証明の利用判断.md)。
