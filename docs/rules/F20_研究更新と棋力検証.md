# 研究更新と棋力検証

各世代の研究更新に数百局の優位性確定を必須にしない。合法性・有限値・保存再読込・盤面復元・教師出所は必須。少数対局は故障と大崩れの検出であり、強化の証明ではない。

固定した研究開始基準、運用チェックポイント、過去複数世代を保存する。定期比較で悪化を検出し、材料不足でも無限に更新を続けず、計画の上限で停止・診断する。巻戻し後も候補・経験は保持する。

- 正式採用は本人判断。正式比較基準を研究用latestへ自動追従させない。
- 同じ実時間・CPU・探索条件、同じ序盤の先後交替を基本とする。評価だけ、探索だけ、組合せの差を分離する。
- monitorと独立auditを区別。局数は効果量・未決着率・予算に応じて決める。40/240局、95%を無条件の固定手順にしない。
- 勝/負/厳密な引分/未決着を全件表示。打切りを0.5点にしてEloを算定しない。ペア単位で不確実性を扱う。普通のp値を繰り返し見て有意な時だけ止めない。
- 損失・深さ・節点・速度は補助指標。実思考時間・超過も併記し、対局で棋力を測る。
- 雲路の長考・先読み・知識・スレッド数は深路の標準設定ではない。対雲路は条件差を表示した別測定。

D17の初期少数局ゲートは未校正の崩壊検出器。中程度の弱化を見逃す危険があり、大量運転前に比較予算を見直す。

- D17実証で全千日手でも周期検査が通過する欠陥を発見したため、周期検査の材料は勝ち/負けの付いた局で数える。通常千日手は正当な引分教師だが、全引分だけで研究の健全性を認定しない。
