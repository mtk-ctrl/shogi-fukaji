# 研究更新と棋力検証

NNUEの各周は現行正式版重みから直接学習を続け、学習前snapshotと学習後重みを直接対局で比べる。独立した研究候補系列を起点・採用判断に使わない。

合法性・有限値・保存再読込・盤面復元・教師出所は必須。比較対局は学習前後の重みの棋力を確かめるため、同一探索設定・CPU・実時間・序盤で先後を交替させる。局数・追加比較の終了条件は実験前に決め、結果を見て都合よく変更しない。統計的有意差を全周の一律ゲートにせず、対局で強化が確認できたら新正式版へ更新し、次の学習をそこから続ける。差が明確でない場合は正式版を維持して比較を追加する。悪化なら学習前snapshotへ戻す。棋譜・前後モデルSHA・全局結果・未決着・合法性を記録する。

正式版のNNUE重み更新は、本人の指示に基づき上記比較通過後に行う。正式USI・探索仕様等の変更はこの自動更新に含めない。

固定した学習前重み、運用チェックポイント、過去の比較結果を保存する。悪化時に復元できるようにし、材料不足でも無限に更新を続けず、各実行の計画上限で停止・診断する。
- 同じ実時間・CPU・探索条件、同じ序盤の先後交替を基本とする。評価だけ、探索だけ、組合せの差を分離する。
- monitorと独立auditを区別。局数は効果量・未決着率・予算に応じて決める。40/240局、95%を無条件の固定手順にしない。
- 勝/負/厳密な引分/未決着を全件表示。打切りを0.5点にしてEloを算定しない。ペア単位で不確実性を扱う。普通のp値を繰り返し見て有意な時だけ止めない。
- 損失・深さ・節点・速度は補助指標。実思考時間・超過も併記し、対局で棋力を測る。
- 雲路の長考・先読み・知識・スレッド数は深路の標準設定ではない。対雲路は条件差を表示した別測定。

D17の初期少数局ゲートは未校正の崩壊検出器。中程度の弱化を見逃す危険があり、大量運転前に比較予算を見直す。

- D17実証で全千日手でも周期検査が通過する欠陥を発見したため、周期検査の材料は勝ち/負けの付いた局で数える。通常千日手は正当な引分教師だが、全引分だけで研究の健全性を認定しない。

## 故障確認とNNUEの棋力比較を混同しない（D24・本人指摘）

- 各4局/2序盤組などの軽量screenは、実装の破損や大崩れの検知に使う。学習による安定した棋力差の根拠にしない。報告では「故障確認」と明示する。
- NNUEの棋力差を調べる比較は、対局前にモデルSHAと世代の意味、共通探索/CPU/実時間、開始局面分布、精度または検出したい差、必要な独立序盤組数、最大局数、未決着、終了条件を固定する。
- 「初期基準」等の曖昧な呼び方だけで報告しない。「初回665局で学習済み（自己学習更新前）」「追加3周直前の第11周」「追加3周後の第14周」等、何を比較したかを併記する。
- 同じ序盤の先後2局を独立2標本として数えない。序盤組を推論単位とし、未決着の結果は0〜1点の未確定幅として分ける。途中の勝ち越しを見て終了/採用しない。
- D24では大きな差を診断するため、独立100序盤×先後2局を各2基準、合計400局と事前設定。2比較同時の標本誤差幅を保守的に約±15ポイント以内とする設計で、微差の確定や一般的な勝率保証ではない。未決着由来の幅は別に加わる。
- 100序盤/200局はすべての学習更新の一律ゲートではない。高速な研究更新を継続しながら、棋力判断を行う節目の比較予算を目的と必要精度から設計する。

## 標準対局条件と強い正式NNUEの選択（2026-11-04追加）

本人の2026-11-04指示により、深路の通常の棋力比較は **1手200ms、各対局・各陣営で1秒の長考を最大10回** を基本とする。長考機会は両者に等しく、使用回数・発動局面・実測時間を全手記録する。標準の比較を100ms固定・長考なしへ無断変更しない。比較計画には同一探索仕様、時間制御方式と発動方針、最大局数、実ジョブ数、評価対象モデルの内容SHAを開始前に固定する。以前の100ms比較は当該条件に限る証拠として残し、標準条件での強さを実証済みと表示しない。

本比較100局は独立50序盤×先後交替の100局とする。本人が20ランナーを指定した場合は、F30に従って20の**独立したGitHub Actionsランナージョブ**を使う。単一PC上の20プロセスや計画文書中の `runners:20` を、実際に20ランナーが稼働した証拠として扱わない。実行できない場合は事前に明示し、同意なくローカル少数並列へ切り替えない。

既に存在するD36・D37の学習済み重みは旧方式の保存成果であっても、正規条件で現行正式版より強いと確認できれば正式版への置換対象とする（[判断記録](../decisions/2026-11-04_標準対局時間と最強NNUEへの更新.md)）。最強と確認できる重みを正式版へ原子的に反映し、次周の学習親はその新正式版のみとする。これは新しい独立研究候補の継続運用を認めるものではない。現行NNUEの採用・強化判断は従来のF00/F10のデータ保護・失敗時の復元を維持する。

D36・D37の過去比較と、ローカル3並列・100ms・26局で止まったD38途中比較は、ユーザー指定の標準比較の代用としない。
