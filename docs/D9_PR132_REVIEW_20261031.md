# D9 PR132：起動前の結果検査修正

対象はPR132の研究用比較基盤。正式エンジン、探索条件、事前固定seed、局数、平均実時間5%・親組p<0.01の停止条件は変更しない。requestはOFFのまま。

## 発見と修正

- 集約器は手数が240以下であることしか確認しておらず、2手で切れた棋譜でも手数上限終了として受理できた。全20分割・40局・先後・SHAが整っていても通り得る。手数上限終了は開始6手を含む240手ちょうどを要求し、実対局の保存時と集約時の両方で確認する。詰み・反復による正当な早期終了は従来の合法再生検査を維持する。
- 終局確認前に探索がresignを返す故障を未決着として処理していた。明示的な故障として拒否し、240局への通過結果に含めない。
- 計画にある中央値・95/99%点・300/500ms超過件数が集約出力になかった。nearest-rank（ceil(p*n)-1）の百分位点と、閾値を厳密に超えた件数を追加した。
- 保存された手番・候補側・時計確認設定・経過時間の型を検査し、真偽値を0/1や時間として受理しない。詰み勝者も整数の手番を要求する。
