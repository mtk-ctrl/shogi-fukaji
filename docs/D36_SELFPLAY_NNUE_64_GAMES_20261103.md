# D36　新しい自己対局64局でNNUEを2回更新

2026-11-03。D35の停止済みアーカイブと再開indexを使い、別領域へ復元して研究モデル `db94693a` と Adam 1722 から開始した。正式版は v0.3.0 の `e0cbd2ab`。

各回で新しい6手序盤16組を選び、先後を交替して32局を指した。両回の相手は正式版。2回目の対局には1回目の追加学習で得たモデルを使った。対局は4並列、双方C++ NNUE・静止探索0・1手50ms・追加256手まで。初期24手では5%の確率で探索着手の代わりに合法手を乱択した。すべての棋譜を再生して合法性と終局を検証した。

各回で新しい決着棋譜と既存の決着棋譜64局から2,048局面ずつ復元抽出した。手番側の終局結果75%と凍結親モデルによるTD(λ=0.8)25%を教師とし、学習率0.001、バッチ128、2エポック、Adamを64ステップずつ継続した。両候補の重みの変化、内容SHAと再読込、optimizerの継続を検証した。学習用の32序盤は今回および過去の評価群から分離した。

実行ドライバは[研究コード](../research/d36-selfplay-continuation/run.py)。既存エンジンと学習器に対する契約検査、関連ユニットテスト38件が成功した。
