# 深路UCT：根の最終手選択を線形化する研究候補（2026-10-29）

## 背景と観測の区別

前回の総時計200ms・同一12親ABBAでは、単一合法手走査ON固定・総時計ONの呼出全体超過が3/24（200.121、200.359、200.039ms）残った。内部時計超過は0/24、呼出全体との差は中央値2.040ms。これは根の最終手選択だけの時間を意味しない。原本に各終了工程の内訳がなく、3件の直接原因は未確定。詳細は `UCT_RETURN_CLOCK_RESIDUAL_AUDIT_20261029.md`。

## 静的に確認した改善余地

現行の最終手選択は `max(root.children, key=lambda c: (c.visits, -root_moves.index(c.move)))` であり、根の子N件それぞれについて先頭から `index` を検索するため、最悪O(N²)。根の子は `root_moves` の順に一度だけ生成され、その後並べ替えないため、同順位の決定は元の添字で代替できる。研究専用の `linear_root_choice=True` だけ `enumerate(root.children)` によるO(N)の走査へ変更。既定はFalseで、正式EngineやG8モデルには接続しない。
