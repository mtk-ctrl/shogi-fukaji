# 深路UCT：合成IPCのUSI順序・stop競合・資源残留検査（2026-10-29）

状態：**研究専用・未採用・既定OFF**。実USI通信、実ワーカー、stdout、実時間保証、G8探索・学習・正式エンジンに接続しない。雲路mainはread-only。

## 対象と検証境界

前段の[応答監督契約](UCT_RESPONSE_SUPERVISOR_CONTRACT_20261029.md)と[履歴付き合法手snapshot](UCT_LEGAL_FALLBACK_HISTORY_PROBE_20261029.md)を受け、`fukaji/uct_synthetic_ipc.py`に単一スレッドの決定論的イベントモデルを追加。実IPCを作らず、`position→go→候補→stop/期限→bestmove送信確認`を外部注入の単調時計で追う。実局面の合法性は別途信頼済みpython-shogiから取得したsnapshotを前提とする。

- `position`は未送信の応答を上書きできず、`go`は事前にpositionを要する。連続goは前回bestmoveの**送信確認後**のみ許す。
- ワーカー候補は監督が観測した受信時刻、世代ID、履歴を含む局面キー、事前の合法手集合で検査。stop後・期限後・旧世代・旧局面・不正手を拒否。
- `stop`は合法fallbackを含む一手を**準備するだけ**。送信失敗は成功扱いせず、外部が実送信を確認した時だけreceiptを生成。stopと送信が競合しても同じ世代からbestmoveを二重送信しない。
- ワーカー停止、資源解放は応答送信と別状態。旧世代の停止通知で現世代を停止済みにしない。送信後も未解放世代を列挙し、資源残留を見える化する。実際の強制停止、解放、監視は実装しない。
- 0反復なら先頭の合法手をfallbackにする。合法手が0の研究モデルではresignとするが、詰み・千日手・連続王手千日手の対局裁定や教師ラベルを生成しない。
