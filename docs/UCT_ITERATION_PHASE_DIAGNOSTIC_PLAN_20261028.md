# 深路G8 UCT時間超過：単一反復の段階別診断計画（2026-10-28）

## 背景と確認済み事実
- [同一12局面ABBA実験](UCT_GUARD_ABBA_RESULTS_20261028.md)では時間予約前24/24回→導入後4/24回の200ms超過。残り4回は50手目の親6（208.129/204.877ms）、110手目の親11（205.373/203.236ms）に集中。
- 現行予約は「これまで最も遅かった1反復×1.5、最低3ms」を次の反復開始前に確保する。初回や過去最長を超える反復を途中停止できず、硬い200ms上限はない。
- 反復ごとの遅延原因はまだ実測していない。合法手列挙・選択・葉評価・逆伝播・盤面復元のどこが律速かは推測に留める。

## 今回の実装範囲
- `fukaji/mcts_research.py` の研究用 `select_mcts` に任意の `iteration_trace` リストを追加。未指定時の探索・評価・選択規則は変更しない。
- 指定時だけ、各反復の選択、展開（合法手生成を含む）、終端判定・葉評価、逆伝播、undo、合計時間、到達深さ、根の合法手数、予約時間、残り時間を記録。
- 盤面の合法性と復元は既存検査に従う。例外時の盤面復元を変更しない。
- 追加の時計呼び出しとリスト書込みにより測定負荷が増えるため、**計測有効の時間を通常の200ms性能測定と直接比較しない**。この機能は原因帰属用であり、棋力や時間制限遵守の証明ではない。
