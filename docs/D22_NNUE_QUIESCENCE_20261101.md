# D22：同じNNUEで静止探索を一要因比較

2026-11-01。[D22 Goal](https://www.addness.com/goals/5bcf5499-c788-45c4-a386-8820f1239c61)。D21の特徴試行とは分け、元の第11周NNUE ac2d9c51を両側で固定する。

## 狙い

研究用探索は末端の局面をそのままNNUEへ渡しており、駒の取り合いの途中や王手回避の前で止まる場合がある。捕獲・成りと王手回避だけを有限の追加手数で調べる経路を実装し、同じ思考時間で有効か測る。雲路や外部AIの評価配点・重み・研究手を移植しない。

- quiescence=0が従来経路。1〜4の整数だけを受け付ける。比較条件は2追加手対0。
- 終局・千日手をNNUE近似値より先に判定する。
- 王手中は全合法回避を候補にし、その場の評価で打ち切るstand-patを使わない。追加手数が尽きた場合は有限深度のNNUE評価へ戻る。
- 非王手では捕獲・成りのみを延長する。非捕獲の王手全般や詰み専用探索は対象外。
- 既存の時間制限、push/pop、反復深化と履歴保護を共用し、ノードごとに期限を検査。静止探索の節点も記録する。指定時間の厳密上限を保証する機能ではない。
- 両側のモデルIDが同一でも、先後交替時に静止探索設定を候補側へ追従させる。

新monitor8序盤の先後16局、100ms指定、最大256追加手。NNUE更新なし、同じ凍結モデルで探索だけを比べる。未決着を引分にしない。正式USIは変更しない。

```bash
python -m fukaji.online_compare --root build/d22-state --left ac2d9c51ceb2979f79be5363f3d1f45bac020bcc9d15d58a3fb67c96145e227f --right ac2d9c51ceb2979f79be5363f3d1f45bac020bcc9d15d58a3fb67c96145e227f --left-quiescence 2 --right-quiescence 0 --name d22-quiescence-arena --seed 202611012200 --pairs 8 --movetime 100 --max-plies 256
```

## 検証と結果

回帰検査は、取り返される駒を静的評価だけでは取りに行く局面、王手中のstand-pat禁止、静かな局面の旧評価一致、時間切れ復元、千日手と詰み、候補側の設定追従を対象とする。回帰用の人工的な駒得重みはtests内だけで用い、学習・対局モデルとして利用しない。実行結果は確認後に追記する。

## 継続学習への設定引継ぎ

自己学習CLIにも `--quiescence 0..4` を明示指定できる。生成、親screen、定期比較の双方に同じ深度を使い、各棋譜とcycle reportのconfigへ保存する。既定は0のまま。探索方式を比較中に勝手に研究既定へ切り替えない。

```bash
python -m fukaji.online_cycle cycle --root build/research-state --cycles 3 --pairs 2 --movetime 50 --max-plies 256 --quiescence 1
```

この例の実行可否は凍結モデル比較の結果を見て判断する。実行済みとは扱わない。
