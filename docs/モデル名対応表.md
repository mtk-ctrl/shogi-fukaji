# モデル名対応表（D／Eの意味と、どれが何か）

最終更新：2026-11-10。現行の正式モデルは **E10**。

## 名前の決め方
- **D番号（D41〜D68）**：以前から続く自己対局の学習サイクルの通し番号。サイクルごとに1つ振る。採用された重みは「D66」のように呼ぶ。
- **E番号（E1〜E4）**：2026-11-09に始めた「NNUE主軸の別系統の実験」。D系の自己対局サイクルと区別するためEを使う。
- E番号は**計画した順**で、完了順・採用順ではない（E1=全局面再学習、E2=探索評価値の蒸留、E3=雲路戦の局面学習、E4=E2蒸留の規模拡大）。
- 採用された重みだけが「現行」になり、旧重みは `models/` に残す。以降もこの表に1行ずつ足す。
