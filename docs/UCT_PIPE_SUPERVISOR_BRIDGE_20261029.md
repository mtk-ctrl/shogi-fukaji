# 深路UCT：実パイプ観測と合成応答監督の限定接続（2026-10-29）

状態：**研究専用・既定OFF・未採用**。正式USI、G8モデル、雲路main、学習、対局、既定値には接続しない。安全拒否の迂回、他run停止、強制的なプロセス終了を行わない。

## 目的と正確な境界

前段の[固定子プロセス・実パイプ検証](UCT_REAL_PIPE_BOUNDARY_PROBE_20261029.md)と[合成IPC状態モデル](UCT_SYNTHETIC_IPC_PROTOCOL_20261029.md)を、最小限の研究専用アダプターで接続する。新規`fukaji/uct_pipe_supervisor_bridge.py`は、**有限の固定子プロセスを実行・回収した後**に、そのパイプ受信観測を合成監督へ時系列再生し、準備された`bestmove`を親が所有する**私設パイプ**へ書込み・flushする。相手側の私設パイプで同一バイト列を読み取る。正式な標準出力、USI GUI、実探索ワーカーは一切使わない。

- 子の`stdout.buffer.write`・`flush`、親の行完成受信、監督による候補受理、親の私設パイプへの書込み、`flush`、私設受信側のreadは異なる境界である。GUI到着の確認ではない。
- 元の`uct_pipe_probe.py`に**改行まで揃った有効候補の親側受信時刻**`accepted_at_ms`を追加。最初のバイト受信時刻とは混同しない。時刻は親の単調時計であり、子が申告する時刻を使わない。
- 合成監督への`go`と合法fallbackの準備時刻は**再生用の0秒**であり、現実の`go`受付からfallback準備までの所要時間を計測していない。候補の受信時刻は実パイプ観測値、`stop`は子回収後の時刻として再生する。したがって**生きた子を監督しながら期限前に応答する実装ではない**。stopと通信の競合や200msの期限遵守を証明しない。
- 合法手集合`('2g2f','7g7f')`は信頼済みの固定**テスト用**データであり、実将棋盤の履歴付き合法性は別モジュール`uct_legal_snapshot.py`の責務。未決着を勝敗・引分の教師に変換しない。
- 私設受信側を閉じる故障注入では`BrokenPipeError`を送信失敗として記録し、送信確認・受信確認を偽装しない。子回収とパイプclose、合成状態の資源解放を別に追跡する。これらはOS全体のFD/メモリ残留ゼロの証明ではない。

## 軽量検証と限界

`tests/test_uct_pipe_supervisor_bridge.py`は12件。正常候補、書込み/flush/私設readの順序、断片化、重複、旧世代、旧局面、破損/途中切断、期限後、stop先行、子異常終了、受信側閉鎖、未知モード・不正入力を検証する。実プロセスの起動と回収を伴うが、重いG8モデルや新対局は使わない。実測はCI環境の遅延に左右されるため、2秒の通常予算と1msの期限後故障注入を使い、**200msの性能数値として流用しない**。

今回の設計で証明できない事項：実USIの`position/go/stop/bestmove`送受信、GUI到着、複数goでの実子競合、協調停止の所要時間、完全資源回収、厳密な200ms保証、棋力向上。次工程は、同じ研究専用・既定OFF境界を維持したまま、**子が生存している間**に親が合法fallbackを準備・期限前送信し、協調停止と残留子を観測できるかを小規模に検討する。実USI正式接続・強制停止・採用には進まない。重い実runを新たに要する場合のみ、27repoの5状態/同目的重複調査、別明示request、固定SHA/全合法性/統計/成果物独立監査、disabled/skipを実施する。
