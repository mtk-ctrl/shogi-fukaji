# 周回を自動でつなぐ（生成→学習→対局→追試→採用→次の生成）

日付: 2026-11-20（本人指示「高速に回数を重ねることが重要なので、できることをやってください」）

## 背景（実測）
- 1周の機械の稼働時間は約3時間（生成61分×2回、学習15〜40分、対局約10分×最大2、採用約3分）。
- 実際の所要は約4時間。差は、完了の確認を人（AI）が定期予約で行っていたための待ち合わせ約110分（追試の起動が33分遅れ、データ区切りの指定ミスを36分放置、など）。

## 決めたこと
- 各workflow（g1-gen・g1-train・hybrid-match・hybrid-nnue-adopt）に、`loop_tag`（空なら手動起動）と、終了を g1-loop.yml に知らせる job を足した。
- g1-loop.yml と scripts/g1_loop.py が、終了通知を受けて次を起動する。状態は loop-state ブランチの state.json（main を動かさない。採用workflowが main の先頭一致を確認するため）。
- 判定はこれまで人が手でやっていたものと同じ：生成2回分（最新3回まで）で学習／ゲート失敗・平均ラベルの偏り（0.40〜0.70の外）は対局せず生成を足して再学習／対局108局で+12以上かつ違法手0なら採用、+6以上は別シードで追試（両方+6以上または合算+24以上で採用）／不採用ならデータを捨てて新しい生成から／採用したら親が替わるので旧データを捨てて新しい親で生成。
- 失敗は2回まで自動で再起動し、3回目で停止する（理由は状態に残る）。採用workflowの失敗は自動で再起動しない（main書き換えのため）。
- 手動操作は g1-loop.yml の event=start/stop/resume/status。止めるときは event=stop。
- Floodgateの記録は混ぜない（負け局300局たまってから別枠。2026-11-20の方針どおり）。
- 試験: `python scripts/g1_loop_test.py`（判定と流れ、ネットワーク不要）。

## 注意
- 人（AI）の確認予約は、停止や停滞の見張りと、判断記録・人生帳への反映に役割を変える。
- 今回の引き継ぎ: 走行中だった周回34の学習（run 44711144353）は通知jobを持たないため、完了後に event=train tag=boot を手動で送って連鎖へ移す。

## 追記（2026-11-20 19:18 本人指示）
検証損失の差が微差（悪化が0.001未満）なら、損失ではなく対局の勝敗で決める。ゲート失敗でも、ゲートを通ったものと同じ基準（単独+12、追試は両方+6か合算+24、違法手0）で対局・採用する（先に入れた「単独+30・合算+24」の厳しい基準は廃止）。損失の悪化が0.001以上や平均ラベルの偏りは、これまでどおり対局せず生成を足して再学習。scripts/hybrid_nnue_adopt.py と g1_loop.py に反映済み。

## 追記（2026-11-21 本人指示「変種の並列学習と、教師の質を上げる案の両方をやってみたら」）
周回35〜37が3連続で不採用（−10、+3、+5）。3回とも学習後に検証損失がわずかに悪化しており、同じ形（1エポック・lr 5e-5・生成2回分・隠れ層128）の頭打ちの可能性があるため、周回の型を2つにして交互に回す。
- **fast**（従来）: 1手50msの自己対局2回分（約1060万局面）を、学習率の違う3変種（1e-5・2e-5・1e-4）で**並列に**学習する（学習は1台ずつで、生成の間に空いている台を使うので時間は増えない）。検証損失が小さい順に1本ずつ対局し、最初に基準（単独+12、追試は両方+6か合算+24、違法手0）を満たしたものを採用する。損失の悪化が0.001以上の変種と、平均ラベルが0.40〜0.70の外の変種は対局しない。
- **deep**（教師の質を上げる）: 1手150msの自己対局3回分（局面数は1回分あたり約1/3で、3回で約530万局面、評価値の精度は上）を、2変種（lr 5e-5・2e-5）で学習する。
- 周回が終わるたびに（採用・不採用どちらでも）fast と deep を入れ替える。親が替わるので、使ったデータは捨てる。
- 実装: scripts/g1_loop.py（MODES）、試験は scripts/g1_loop_test.py。変種は1本が失敗しても、その1本だけ再起動し、3回失敗したらその変種は見送って残りで進める。
- 結果は state.json の history に変種名つきで残る。どの型・どの学習率が効くかは、採用や勝敗差の記録から後で比べる。
