# 2026-11-07 D46：実棋譜で見えた基本戦術・将棋らしさの課題

## 発端

本人がShogiDroidで[D43学習後が勝った1局（family-000-candidate-black0、282手、後手D43勝ち）](https://github.com/mtk-ctrl/shogi-fukaji/releases/tag/fukaji-d43-shogidroid-150-20261107)を確認。評価：「まだ全然将棋のカタチになっていない。詰みを見逃す、取られる場所に駒を打つ、王への攻めが弱く、合法手から適当に選んでいるように見える」。

D43 vs D37の200局でD43が150勝50敗という結果は、**同じ弱い探索枠組みで古い重みに勝った相対的改善**を示すにとどまり、絶対的な将棋の強さ・基本戦術の妥当性は実証していない。今後は同系列の勝率だけを唯一の品質指標として扱わず、実棋譜での戦術品質も計測する。本人の指摘を先に研究へ反映し、次周1000局の繰返しだけを目的化しない。

## コードで確定した原因・限界

1. **比較対局も最初の6手は完全ランダム**：`fukaji/arena.py` の `opening(seed,6)` は各手の合法手から一様乱数で選択。 `fukaji/online_cycle.py` の `fresh_prefix` が使用。D43 vs D37 200局の第1～6手はこの生成手順であり、学習後モデル自身の選択ではない。比較対局の残りの手は探索の選択で、D42/D43監査の `exploration_probability=0`。自己対局trainでは別途、初期24追加手の5%ランダム手を許す。これを混同しない。
2. **C++ NNUE探索は`quiescence=0`固定**：`native/nnue_search_ffi.cpp` `NSearch::search` は深さ0の瞬間にNNUE静的値を返し、取り合い・王手延長・駒を取り返すまで読む静止探索がない。 `fukaji/native_nnue.py` `NativeSelector.select` は`quiescence != 0`を拒否。深さが薄い局面では地平線効果が生じる。
3. **深さ0の手選択が局面評価を通らないことがある**：`native/nnue_search_ffi.cpp` のroot `best=moves[0]` とするfallbackを確認。時間内に初回反復深化（深さ1）を完了できなければ、駒取り・成り中心の`moves()`の先頭を採用しうる。読み切ったbestと未完了の部分探索をテレメトリで別扱いにすべき。
4. **評価器の特徴量・容量が限られる**：現行モデルは`2548入力×32ユニット`の小規模NNUE。既存`fukaji/nnue_research.py`にはキング相対特徴量の設計があるが、現行`fukaji/native_nnue.py`の学習済みC++推論器は2548の絶対配置特徴量のみ受け付ける。玉と攻め駒の相対関係、玉型、駒連携に弱い可能性が高い。弱さの寄与率は未測定。
5. **勝敗教師は悪手を除去しない**：D43/D45は「勝敗75%＋凍結親TD25%」で局面を学習。勝った将棋の全着手が正しいわけではなく、特に同等の弱い相手との自己対局では互いの戦術ミスが残る。これは教師品質と探索性能の問題を分けて検証する必要がある。

## 実測診断（独立ジョブ）

- D46検査は[D46 GitHub Actions](https://github.com/mtk-ctrl/shogi-fukaji/actions/runs/42328479519)に配置。実際の282手原棋譜と200局Release SHA256 `c08ccab3…`を検証し、全手の探索深さ、深さ0・1比率、双方の詰み1手の見逃し、取られる升への駒打ちと次手で合法に取れるものを数える。
- **まだ出ていない計測値を推測で埋めない**。`research/d46/282ply-d43-depth-mate-drops.json`はジョブが成功した場合にのみ生まれる。駒打ちが攻め・捨駒である可能性もあり、「攻撃されている升への打」をただちに悪手と断定しない。
- 1局の診断は代表サンプルではない。定量評価にはD43監査200局の全棋譜や未見局面集での追加計測が必要。

## 次に進める研究の優先順位（案）

**優先1：探索の最低限の戦術精度を上げる。** 基本の詰み1手、王手回避・連続王手の詰み、駒取り・取り返し、駒打ちへの合法応手を評価する局面テスト集を固定。C++ NNUE版に静止探索（王手中の全合法回避＋平時の取り／成り）を研究枝で実装・比較。検索時間200msが同じ条件で、実効深さ・nodes・超過を測り、棋力・戦術失敗率の両方で採否を決める。**実行時間を無視して深さだけ増やすのは不可。** 深さ0fallbackと未完了反復深化がどの程度発生したか先に定量化する。

**優先2：序盤の無意味な開始形を改善。** 自己対局の対局生成に適した開始局面を検証。ランダム6手からの比較は過去実験との一貫性のため変更しないで保全し、別の現実的な合法序盤群での新しい比較を追加。棋力測定で「序盤6手はモデルの意思決定ではない」を必ず明示。

**優先3：NNUE評価の玉型・安全・攻撃への表現力を研究。** 既存 king-relative 設計のC++サポート、モデルサイズ・学習データ量との釣合い、玉・持駒・守りを測る独立局面集を調査。駒得だけでなく相手玉への寄せと自玉の危険を評価できるようにする。学習条件とモデル比較が混ざらないよう、研究テーマを分ける。

**優先4：教師品質の改善。** 勝敗学習の高速反復は継続しつつ、実戦勝利だけでは保証されない「1手詰みを逃さない」「明白なただ捨てを避ける」などの客観的な局所指導信号を追加検討。評価専用棋譜の学習利用禁止を維持し、出所を明確化。

**検証の最終指標**：既存D43を固定して、変更前後の独立序盤・同一200ms長考条件での実際の勝率（最低限100序盤×先後200局）に加え、保護された戦術局面での詰み1手・詰み3手の正解率、取られる駒打ちの危険率、探索深さと時間超過を報告。静止探索単独・NNUE学習単独の効果を識別する。強くなることが主目的で、実験数は手段。
