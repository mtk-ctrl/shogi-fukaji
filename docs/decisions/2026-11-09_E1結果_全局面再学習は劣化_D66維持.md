# 2026-11-09 E1結果：過去の全自己対局の全局面で再学習 → 大幅に劣化、D66維持

## 実験
- D66(Adam11864)から、D43〜D68の自己対局1000局×12＋bootstrap665局（重複除去後12,665局、うち学習用11,981局・学習から除く5%の評価用684局）の全局面(117.5万局面)で3エポック、lr 0.0002。TD-λ=.8、結果重み.75は従来どおり。
- run 42553499456（workflow e1-nnue-retrain-audit、scripts/e1_train.py、候補重みはFUKAJI_CAND_NPZで差し替える scripts/fukaji_cand_engine.py）。探索・時間(200ms)は両者同一。

## 結果（事前基準：候補がD66より12勝以上多ければ採用候補）
- D66 142勝 / E1 54勝 / 引分4（200局、リプレイ検証済み・違法手なし）。ペア全勝 D66 48 / E1 5。**不採用、D66維持。**
- 評価用棋譜の損失 0.5966 → 0.6091（悪化）。強さと同じ向きで悪化しており、学習が劣化方向だったことと整合する。

## 原因の見立て（未検証の仮説）
- 古い世代（弱い方策）の棋譜を大量に混ぜると、現在のD66の分布から外れる。ラベルの半分は棋譜の勝敗(z)で、古い弱い局面の勝敗は現在の評価の教師として質が低い。
- これまでの1000局×1回の更新が「ほぼ横ばい」だったのは、データが新しく少量だったため。データ量を増やせば伸びる、という単純な見立ては誤りだった。
