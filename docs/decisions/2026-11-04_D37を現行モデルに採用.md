# 2026-11-04：D37を「現行モデル」に採用し、そのまま自己対局強化へ移る

## 理由と本人判断
2026-11-04の本人指示「もうd37を現時点の正式版にして、自己対局をやったらいいんじゃないかな？正式版っていう名称もわかりにくいけどね」を採用する。旧「正式版」は以後の説明では**現行モデル**と呼ぶ。「学習前snapshot」は**更新前モデル**、「学習後」は**学習後モデル**と呼ぶ。旧資料の当時の名称は歴史的表現として保持する。

一度だけ、過去に別の研究系列として作ったD37の学習済み重みを、今回の明示指示により現行モデルとして指定する。以後は追加の独立研究系列を育てず、各学習周で現行モデルを起点とし、更新前モデルを不変に保存→自己対局→学習→更新前後の直接比較→改善なら新現行モデル、とする。複数AIは同じGitHub mainと本人限定Driveを正本にする。

## 実際の比較・採用根拠
- 旧現行モデル：D33/e0cbd2abe53b1d151bb73407f848b4087456c1466121333ad490a96aee131b0a、Adam1708、FUKAJI v0.3.0。
- D36：7d74b86bcd5bd1a0e7cefc10f8d01cd2c816822ac4636e6f1603795fab9dcf6b、Adam1850。
- **新現行モデルD37最終**：170d6c1ee41d77b69f0b75722ece3deb85f3eea189f70d9789db477a38266db1、Adam2106。
- 既存D37完了アーカイブを実取得・復元し、D37 vs D36の独立100序盤/先後200局（**1手100ms・q0・長考なし**）で129勝66敗1厳密引分4未決着を確認。D36 vs e0の400局は241勝150敗1引分8未決着。この分布での明確な勝ち越しが選定根拠。
- **本人が指定する1手200ms、長考1秒を最大10回/陣営の正規時計比較は、この採用時点で未実施**。今回の採用は本人の明示指示を優先したもので、正規時計で強さを実証済みと主張しない。比較に必要な時計・長考制御と20独立Actions runnerは別途実装・検証する。
- D38として実行した3並列・100ms・26局は指定条件不一致として今回の採否判断から除外する。

## 次の工程
1. D37を現行モデルとして保存、次の学習周の不変更新前snapshotはD37 `170d6c1e`。二重writer防止のためActions・mainとDriveの最新版を作業前に確認。
2. D37の完全stateを再開して、200ms通常＋1秒長考最大10回/陣営で自己対局生成。結果の確定・未決着を区別し、個別ゲームを保存、20ランナーなどの実利用数は実ジョブIDで監査する。runnerへのprivate重み安全受渡しができない場合、無断で公開する代わりに安全な範囲のローカル検証として区別する。

4. GitHub ROADMAP・GitHub D系・本人限定Driveへ実局数、条件、欠損、実行run、SHA、保存読戻しと次周入口を記録する。
