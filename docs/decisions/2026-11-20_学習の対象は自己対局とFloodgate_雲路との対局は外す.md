# 学習の対象は「自己対局」と「Floodgateでの対局」。雲路本体との対局は学習から外す

- 日付：2026-11-20（本人指示）
- 決めたこと：学習データは、①E26など現行の深路どうしの自己対局、②Floodgateでの実対局、の2種類にする。雲路本体を練習相手にした対局は、学習に使わない（対局の比較・採用判定で雲路と指すのは別の話で、変えない）。
- 理由：雲路相手のデータは、深路が圧倒する局面に偏り、平均ラベル0.727で候補が24-84と大敗した（周回30）。Floodgateは外部の多様な相手との実対局で、持ち時間が長く、探索値の質も高い。
- 実装：`scripts/floodgate_to_g1.py` と `.github/workflows/floodgate-data.yml`。Floodgateの対局記録(floodgate-live-<run>アーティファクト)から、深路の手番の探索値(score_black_view)と勝敗だけを取り、G1学習データ(`g1-data-floodgate-*`)に変換する。相手手番の評価は使わない。詰みスコア・結果不明の対局は除く。従来の記録側の `learning_eligible=False` は、この本人決定により学習に使う（変換結果に出典を残す）。
- 使い方：floodgate-data.yml を起動して得た run ID を、g1-train.yml の data_runs に、自己対局の生成runと並べて指定する。
- 注意：Floodgateの対局数は1日あたり数十局と少なく、自己対局（1周で約12万局）に比べて量はわずか。蓄積して使う。多様な相手と深い探索の局面を足す役割で、量での改善は自己対局が主。
