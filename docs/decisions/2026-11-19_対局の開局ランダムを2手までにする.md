# 対局（hybrid-match等）の開局ランダムを6手から2手へ（2026-11-19）

本人指示：「ランダムは最初の二手目まででいい。いくらなんでもって気がする」。

## 背景
- 対局の最初の6手を合法手からランダムに選ぶ設定(`scripts/usi_match.py` の `--opening-plies` 既定6)だった。
- 直近の棋譜（周回25候補 対 現行E23）では、2筋の歩を2回突く等の不自然な序盤が実際にはランダムの手で、AIの意図ではなかった。AIの手と見分けがつかず、棋譜の評価を妨げる。

## 変更
- `usi_match.py` の play / pair の `--opening-plies` 既定を 2 に変更（開局は 約900通りから重複なしで選ぶ。54ペアに足りる）。
- 対象は対局（比較・採用判定・棋力測定）のみ。学習データの自己対局生成（g1_gen.py の `--opening-plies` 既定8）は別目的（局面の多様性）なので変更していない。

## 注意
- 開局が自然になるぶん、勝敗差の基準（+12等）の分布が変わる可能性がある。以後の周回は新しい開局で比較される。
