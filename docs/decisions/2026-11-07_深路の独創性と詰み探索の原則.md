# 2026-11-07：深路の独創性と詰み探索の原則（本人の明示判断）

## 目的と変更理由

2026-11-07、本人はShogiDroidで深路D43の実棋譜を確認し、将棋として不自然な動き・詰みの見逃しを指摘した。その後、**「戦術というか、せめて詰みはいるよね。定石とは覚えさせたくないのよ。アルファ碁がやったような方法で、今までの常識にない手を想像してほしいから。このコンセプトは外さないでほしい」**と明示した。

深路の最優先は**人間の定跡・戦法・良い手の常識を与えず、将棋のルール・勝敗・自己対局・探索から、AI自身に勝ち方と新手を発見させること**。いわゆる初期AlphaGoの棋譜教師（人間の棋譜からの模倣）ではなく、**AlphaGo Zero / AlphaZero型の「ルール以外の人間の棋譜知識なし・自己学習」というコンセプト**に近い。これは特定の探索アルゴリズムを無条件で採用する命令ではない。

参考：[AlphaGo Zero（Google DeepMind）](https://deepmind.google/blog/alphago-zero-starting-from-scratch/)、[AlphaZero（チェス・将棋・囲碁、Google DeepMind）](https://deepmind.google/blog/alphazero-shedding-new-light-on-chess-shogi-and-go/)。

## 必須原則

1. **詰みは教科書的な知識ではなく勝利条件そのもの。** 将棋の合法手・王手・王手の合法回避・詰み／被詰み・反則・千日手等を正しく扱い、探索によって詰みを発見することは絶対に妨げない。まず合法手を使った**1手詰みの全列挙・詰みの見逃し回避**を実装・検証し、次に受けの全合法応答を含む**詰み3手・5手等の強制手順の探索**へ拡張する。詰み筋や囲いを人手で記憶させるのではなく、盤上の合法手と勝敗条件から導く。
2. **定跡・戦型・囲い・手筋・人間の「常識の好手」を教師として固定しない。** 定跡書、棋譜DB、他将棋AIの推奨手や評価値、駒得・駒組み・玉を攻めるべき位置への人手配点を学習教師へ無断で混ぜない。定跡通りか、棋士らしいか、珍しい手かではなく、**未知の相手にも勝てるか**で判断する。
3. **探索の強化と人間の評価関数の移植を区別する。** 静止探索・合法な王手応手・チェックメイトの完全検証・時間切れfallback改善は、ルールにもとづく正確な先読みの改善候補。取りや成りを機械的に良手にする、駒を損する手を自動で禁止する、特定の升への駒打ちを悪手と決める、既存の定跡から出る手を優遇する実装はしない。**意図的な捨駒・不利に見える新手も合法なら探索候補に残す。**
4. **自己対局を中心に学習**する。学習対象は実際の合法局面と勝敗結果を基本とし、探索が改善した着手分布などを採用する場合も、外部の「正しい人間の手」ではなく現行モデル自身の探索・自己対局から生成する。人間のプロ棋譜を正解教師にしない。
5. **偶然のランダム手と創造的な選択を混同しない。** 現行D43/D45は比較開始の最初の6手を合法手から一様乱数で選び、その後も一部の自己対局trainで乱数探索がある。これは多様性のためのデータ生成であって**独創的戦略の発見ではない**。既存実験の条件を後から書き換えず、次の実験で「初期局面から現行モデルが探索した手＋十分に制御した探索的変化」による自己対局を別途設計する。人間の定跡を使って置き換えない。
6. **詰み正答率と相対勝率は別々に検査。** 学習前後の独立200局比較を引き続き行う一方、ルールから導いた詰み1手・3手・5手（攻方全手・受方全合法応答を検証）と、実戦の詰み見逃し・詰まされ防止を測る。合否は実測値で判断。奇抜さそのものに報酬を与えたり、人間の定跡に似ているかどうかで点数を付けたりしない。
7. **AlphaZero型の方策・価値・探索の相互強化を検討する。** 手分布（policy）と勝率予測（value）を自己対局から学習し、探索で候補手を改善し、探索結果を次の自己対局へ戻す仕組みは有力。MCTSと既存NNUEの費用・速度・実棋力を比較して判断し、単に名称だけを模倣した実装や見た目の新手は採用しない。

## 成功条件

**定跡を暗記しているから強い**のではなく、**詰みを見落とさず、勝敗につながる手を自ら読み、常識外の合法手も勝つなら選べる**深路にする。詰み探索などの知識は「人間の好手」ではなくゲームのルールに従って正解を計算する仕組みであり、独創性を制約しない。
