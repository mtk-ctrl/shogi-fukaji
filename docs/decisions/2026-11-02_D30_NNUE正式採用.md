# D30 NNUEの正式採用

2026-11-02。本人の明示指示「正式反映させてください」により、D30研究候補912db54fをFUKAJI v0.2.0として採用する。F20の本人判断を満たすため、再確認や新たな棋力閾値を要求せず実装・配布を仕上げる。

採用範囲は同一NNUEと既存C++基本探索を正式USIへ接続すること。D28差分演算・別のNNUE・静止探索・新教師方式は一括採用しない。stop用atomicフラグを追加し、無効時の探索結果一致を検証する。

D30の400局224勝168敗1分7未決着は第15周との比較である。事前区間46.522〜67.478%のため安定した優位の確証とは記さない。正式採用と研究の不確実性は両立する。

以前、公開許可不足で学習データの公開送信が拒否された。今回は公開コード・固定manifest・文書と、本人限定Driveの推論重み同梱パッケージを作る。正式採用指示を学習データ全体の公開許可へ拡張しない。モデル欠損を旧評価で隠さない。

旧v0.1.0、固定比較基準、研究snapshotとoptimizerを保全する。正式モデルを研究latestから独立させる。仕様と検証・保存先は [D32](../D32_FORMAL_NNUE_RELEASE_20261102.md) を参照。
